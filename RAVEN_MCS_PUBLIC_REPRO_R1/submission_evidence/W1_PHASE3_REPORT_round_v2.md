### 3.1 稳定性警告（必须与 `G_F` 一起报告）

- U-Air `R_on` 的分母 `Δ_unif − Δ*` 只有 `0.0263 ± 0.0114`（变异系数 43%），因此**每种子比值法（协议 F2 的字面读法）在该格子上不稳定**：`G_meanratio = 0.124`，种子标准差 `0.383`，个别种子分母接近 0 使比值发散。`G_ratio = 0.189` 才是稳定读数。
- SensorScope 的分母 `0.0688 ± 0.0164`（CV 24%）也偏小，两种读数的差异较小（0.1877 vs 0.1887）但不为零。
- **协议 F2 的 `NA_degenerate` 阈值（分母 < `1e-6`）不足以拦截这种小分母发散**——它只拦严格退化。脚本已按 CV > 25% 自动打标：**70 个 P2 比值格子中 31 个被标 `G_fragile_small_den`**（见 `G_F_BOTH.csv`，含 c-s 端点几乎全部格子）。建议在 Phase 4/5 与写作中：只要分母的种子标准差与其均值同量级（CV ≳ 25%），就**以绝对差 `Δ_unif − Δ_rule` 为主读数**，把 `G` 作为辅助。本条为对协议的观察，不改变任何已冻结阈值。

### 3.2 三条可在论文里用的读数（绝对量为主，数字化、不越界）

1. **同支持、事后最优下，结构端点的可回收余量本身很小**：SensorScope 均匀权重的 `Δ_unif/2 = 51.3%` 目标质量错配中，只有 `(Δ_unif − Δ*)/2 = 3.44 pp` 可回收，其余 `Δ*/2 = 47.9%` 同支持不可消除；U-Air `R_on` 为可回收 **1.32 pp**、不可消除 **53.6 pp**（`Δ*/2`）。这里的 pp = 概率质量百分点（`TV = Δ/2`，`M` 的列和为 1、`Σμ = 1` 已实测确认，故 L1/2 即总变差）。
2. **Design 规则回收的是"更小的一块"**：RAVEN 相对均匀权重的结构 L1 改善 `Δ_unif − Δ_rule` = **0.01299（SS）/ 0.00498（UA `R_on`）**，即 `0.65 pp / 0.25 pp` 目标质量；占可回收余量的 `G_ratio = 18.9% / 18.9%`（c-s 端点 `21.2% / 24.4%`）。
3. **去掉 Design（`raven_wo_design`）在同尺子上不回收余量**：SS `Δ_unif − Δ_rule = 0.00044`（`G_ratio = 0.0064`）、c-s 端点比均匀更差（`−0.00124`，`G_ratio = −0.0418`）；U-Air 在它自己的 `R_offp` 上 group `−0.00008`、c-s `−0.00016`（均为负）。Design 开/关的差异**只能各自对自己的 `Δ*` 报 `G`/绝对差**，不能跨尺子相减。
4. **`debt_cal`（Design 关、无观测 IPW、只留 debt）在结构端点上不如均匀权重**：SS group `Δ_unif − Δ_rule = −0.00032`（`G_ratio = −0.0046`）、c-s `−0.00028`（−0.0095）；U-Air group `−0.00026`（−0.0099），c-s `+0.00065`（+0.0218）。该臂已按 P2 臂处理（其 `α` 通过 `C_r` 前置检查，最大违反在求解器容差内），并纳入 F1 闸门（0 违反）。

## 5. 记录在案的技术细节（不进论文，进复核材料）

1. **c-s 端点的归一化是恒等操作**：任一可行 `α`（均匀、尺子臂、`λ=∞` 最优解）下 `Σ_keys (1/S)Σ_r α_{k,r} w_{k,r,s} = 1`（实测偏差 0 / 1.44e-12），冻结实现里的 `agg/tot` 归一化不改变数值（`|raw − normalised| = 0 / 1.35e-12`）。
2. **`pair_state.w_atomic` 在一个 `(窗口, 客户端)` 块内均匀且求和恰为 1**（SensorScope seed 30001：257 个客户端-窗口块，块内 1/2/3/4 行的块数分别为 119/96/38/4，多行块的权重全部相等），因此任一行权 = 1/该客户在该窗口的原子单元数；`Σ_c α_{c,r} = 1` 使键级总质量恒为 1（实测偏差 0 / 1.44e-12）。**更正**：不是"每客户端每窗口一行"——多行块占 88/97 个活跃窗口。`Δ_c-s` 的键级质量是 `α_{k,r}·w_atomic/S`。
3. **LP 与冻结端点在 `λ=∞` 最优解上的残差最大 5.10e-6**（80 单元最大值；同一单元均匀 `α` 下为 6.44e-15）。来源是求解器返回点的可行性误差（`max_r |Σ_c α − 1| ≤ 8.3e-11`）经非光滑 L1 放大，不是矩阵或归一化差异。因此 `Δ*_cs` 的有效位数为小数点后 5 位；论文层面使用 4 位以内。
4. `C_r` 前置违反量级：P2 臂 ≤ 2.10e-8（求解器容差）；`twostage_hajek` 0.457、`local_hajek` 0.300（不作为 P2 求解，天然在 `C_r` 外）。**基线臂的 `G_F` 因此不可与 P2 臂并列解释**，已在 `FRONTIER_ARMS.csv` 中以 `cr_class` 标注；`G_F_means` 按类别分组。
5. `w_mass_min/max = 1.0/7.0` 是"每客户端 `w_atomic` 之和 = 1、活跃客户端数 1–7"的体现，不是质量不守恒。
