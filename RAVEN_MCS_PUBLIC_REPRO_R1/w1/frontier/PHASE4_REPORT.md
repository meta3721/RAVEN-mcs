## 4. 按预注册判定表机械判定（`R_on`）

| 数据集 | 端点 | 触发条款 | 允许写的结论 |
|---|---|---|---|
| SS | group / cs | 第 1 行（`L6−L5` 区间 ⊂ ±τ_eq = ±0.10） | **debt 对结构端点无独立贡献（在登记等价界内）；debt 只保留为可审计记账** |
| UA | group / cs | 第 1 行 | 同上 |
| SS | group / cs | 第 2 行（`L5−L3` 区间 ⊂ ±τ_eq）亦成立 | **结构收益来自"在 `C_r` 内做目标匹配"；P2 的其余项不是必要的** |
| UA | group / cs | 第 2 行亦成立 | 同上 |
| 全部 | — | 第 3 行（要求 L5 的 `G` 下界 ≥ τ_near = 0.80）**不成立**（L5 的 `G` ≈ 0.17–0.24） | 不得写"完整 P2 必要且接近同支持最优" |

两点必须同时写出的限定：
1. `L6−L5` 虽在 ±τ_eq 内，但**不是严格零**：Holm 显著、幅度 ≈ 1e-4（≈ 0.2% 可回收余量）。正确表述是"在登记的等价界内无独立贡献"，而不是"完全无影响"。
2. τ_eq = 0.10 是**在 Δ 单位**上登记的（预注册原文），而观测到的档间差为 1e-4~1e-2 量级，因此第 1、2 行天然容易触发；`G` 单位读法（±0.10）在第 1 行同向成立（`ΔG` = +0.001~+0.002）、在第 2 行亦成立（`ΔG` ≤ 0.004）。两种单位读法给出同向结论（PHASE3_REPORT §3.1 的同类观察）。
