# THEORY_NOTE

日期：2026-10-19。这些短证明只说明可行权重的几何性质。它们不保证预测误差下降，也不代替 S2 的验证评分。

冻结约束与代码一致。`alpha_bar` 是 `min(1, max(alpha_max, 1/K))`，`ess_ball_bound` 是 `min(E_min, K)`，约束为权重平方和不超过 `1/E_bar`。已确认来源把 `alpha_max` 定为 0.5，把 `E_min` 定为 3。见 `src/raven_mcs/aggregation/feasibility.py` 与 `scripts/w1_v4_train.py` 的 `ALPHA_MAX, E_MIN = 0.5, 3.0`。论文正文用符号写出同一形式。没有发现需要改 cap 或 ESS 的冲突。

## 存在、唯一与约束

非空窗口里，Uniform 的每个坐标是 `1/K`。cap 至少是 `1/K`，所以 Uniform 满足上下界。Uniform 的平方和是 `1/K`，而 `1/E_bar` 至少是 `1/K`，所以它满足 ESS 球。可行集因此非空。它是线性等式、盒子约束和球约束的交集，闭且有界，所以紧；每个约束都是凸的，所以可行集凸。

目标是到参考向量的平方距离，Hessian 是单位阵，严格凸。紧凸集上的严格凸连续目标有唯一最小值。因此归一化、cap 和 ESS 在这个唯一解上成立。

`K<=3` 时 `E_bar=K`，平方和约束变成不超过 `1/K`。单纯形上的平方和最小就是 `1/K`，只在 Uniform 取到。所以这时可行集只剩 Uniform。`K=2` 时 cap 也是 0.5，两个权重都不能超过 0.5，同样只剩 Uniform。这个事实只解释投影没有活动空间的窗口。本方案不放宽 ESS 去制造非退化窗口。

## 相对可行参考的几何性质

设 `alpha_P` 是参考 `beta` 在可行集上的唯一投影，`a` 是任意可行权重。凸集投影满足 `(beta - alpha_P)` 与 `(a - alpha_P)` 的内积不超过 0。展开 `||beta - a||^2`，得到

`||alpha_P - a||^2 <= ||beta - a||^2 - ||beta - alpha_P||^2`。

这只说明投影比原来的参考更接近每一个可行权重。它不说明目标组失配、RMSE 或真实风险会下降。

## 未覆盖组不能被投影补出来

设每一列 `M` 都是一个组和为 1 的构成，`alpha` 的和也是 1，目标 `mu` 的和是 1。若某个组在所有活跃客户端上的构成都是 0，则任何可行权重给出的该组质量仍是 0。两侧都是概率向量时，总变差至少是这一组目标质量之和，所以

`0.5 * ||M alpha - mu||_1 >= sum_{g in Z} mu_g`。

投影不会创造这些组的实际支持。该下界是逐窗的。它不能直接写成跨窗累积端点的同一个下界。权重可行或 ESS 达标，也不表示参考无偏或预测安全。若要陈述目标恢复，仍须使用原有的正性、选择机制可识别性和稳定化误差条件。
