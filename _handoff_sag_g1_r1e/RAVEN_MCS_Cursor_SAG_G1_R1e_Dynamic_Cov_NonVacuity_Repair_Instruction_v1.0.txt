四、先修一个明确的 evidence-builder 语义 bug
================================================================================

R1d 源码中存在类似：

  certified = float(
      cov_info.get("target_mass_certified") or float("nan")

  target_mass_certified = 0.0

  raw_certified = cov_info.get("target_mass_certified")

      certified = float("nan")

      certified = float(raw_certified)

- missing 才能是 NaN；

六、R1e-A：对 R1d 的 vacuity 做四层归因，先不改 predictor

---------------------------------------------------------------------
A. realized support coverage diagnostic
---------------------------------------------------------------------

定义：

  C_real_support(r)
  =
  [sum_{k,s} pi_tar(k,s)
     1{ pi_opp_realized(k,s,r) > 0 }]
  /
  [sum_{k,s} pi_tar(k,s)]

注意：

- 这是 post-hoc development diagnostic；
- current-window realized opportunity 绝对不能进入同一 window Gate；
- 不得把它命名为 certificate。

另外保留：

  realized_opp_event_mass_total(r)
  = sum_{target-positive pairs} pi_opp_realized(k,s,r)

不要混淆：

  realized opportunity event mass

与：

  target mass whose pair is realized-supported。

---------------------------------------------------------------------
B. point-predictor support
---------------------------------------------------------------------

定义：

  C_point(r)
  =
  [sum pi_tar(k,s)
     1{ pi_hat_opp(k,s,r) >= pi_safe }]
  /
  [sum pi_tar(k,s)]

这个对象不减 conformal q。

它只用于回答：

  “certificate 变 0 是 predictor 本身就预测不出来，
   还是 calibration penalty 把它压成 0？”

---------------------------------------------------------------------
B.1 current-window context 的合法来源
---------------------------------------------------------------------

current-window context 只能来自：

  public clock / fixed window schedule

使用与论文 deployment group 相同的 UTC 6-hour block：

  H1: 00-06
  H2: 06-12
  H3: 12-18
  H4: 18-24

即：

  RepeatableTimeOfDayMapper_UTC_hour_floordiv_6

非常重要：

不得通过“当前 window 第一条 EventTrace event 的时间”来推断当前 block，
如果该第一条 event 的存在本身依赖当前 R/O/U。

必须找到 pre-window 已知的：

  window schedule / window boundary / public timestamp mapping。

新增：

  R1E_WINDOW_CONTEXT_PROVENANCE.md

说明：

  window_id -> public window timestamp -> TOD block

是如何在当前 window opportunity/outcome 被观察前得到的。

如果 repo 中根本不存在合法 pre-window schedule，
且必须读取 current-window event 才知道 block：

  verdict = NO_LEGAL_PREWINDOW_CONTEXT_FOR_R1E
  STOP。

绝对不允许为了继续实验而偷偷使用 current R/O/U。

---------------------------------------------------------------------
B.2 predictor 定义，预注册且固定
---------------------------------------------------------------------

对 pair j=(k,s)，当前 window r，current public TOD block = h_r。

设：

  H_same(r)
  = strictly prior completed windows t<r
    with h_t = h_r

取 H_same(r) 中最近最多 L=8 个 completed windows。

如果 H_same 非空：

  pi_hat_ctx(j,r)
  = mean_{t in last-8 same-block prior windows}
      pi_opp_realized(j,t)

注意：
  zero opportunity mass 必须作为 0 进入均值；
  不能只平均 positive windows。

如果 H_same 为空：

  fallback 到 R1d frozen global rolling rule：

  pi_hat_ctx(j,r)
  = mean of last L=8 strictly prior completed windows。

如果连 global prior history 也不足以满足现有 cold-start protocol：
  fail closed。

本轮不引入额外可调 alpha / decay / regularizer。

不做 weighted tuning。

---------------------------------------------------------------------
B.3 必须保留的信息边界
---------------------------------------------------------------------

TOD_CONDITIONED_ROLLING_V1 可以使用：

  - t<r completed pi_opp masses；
  - current public TOD block from fixed schedule；
  - frozen pi_tar；
  - frozen pi_safe。

不得使用：

  - current R；
  - current O；
  - current U；
  - current labels；
  - current residual；
  - current realized pi_opp；
  - current Gate result；
  - dataset name as a predictor feature；
  - RMSE；
  - future windows。

十一、R1e-C Stage 2：唯一允许的 calibration repair

---------------------------------------------------------------------
C.1 residual 定义不变
---------------------------------------------------------------------

每个 completed window t：

  R_t
  =
  max_{target-positive pairs}
    [ pi_hat_ctx(j,t) - pi_opp_realized(j,t) ]

---------------------------------------------------------------------
C.2 q_r 只允许按 public TOD block 条件化
---------------------------------------------------------------------

current block = h_r。

取 strictly prior：

  { R_t : t<r, h_t=h_r }

如果同 block prior residual 数量 >= 8：

  q_r
  = conformal_upper_residual(
      same-block prior residuals,
      delta=0.05
    )

如果 same-block prior residual 数量 < 8，
但全局 prior valid residual >= 8：

  fallback 到 global prior residual conformal q。

如果 global prior valid residual < 8：

  cold start / fail closed。

不得：

  - 降 delta；
  - 手工缩放 q；
  - q *= 0.5；
  - clip q 到 pi_safe；
  - outcome-conditioned q；
  - dataset-conditioned q；
  - performance-selected q。
