# W1 展开分析：完整方法的"必要性"缺口，以及它现在只能怎样被闭合

```text
对象：外部评审（ccfa-review-reports/raven-mcs-unspecified-venue-review.md）的 major W1
当前稿：TO_OVERLEAF_paper_tmc_r1_clean（main 17 pp. + supplement 16 pp.，items 33–52 之后）
结论一句话：W1 的"必要性"不能再用预测端点来论证——论文自己已有四条独立证据表明预测端点在本 regime
          不可移动；它只能（且应该）在【结构端点 + 同支持对照 + 代价】上闭合。
```

## 1. W1 的原文要求，拆成三个可检验的子问题

| 子问题 | 原文措辞 | 检验方式 |
|---|---|---|
| **S1 实际意义** | "需解释 `Δ_group` 的实际意义、残余误差" | 把 `Δ_group` 与 `Δ_c-s` 映射到可解释量：目标质量的错配、被服务质量的缺口；并说明残余 L1 的量级 |
| **S2 同支持最优** | "以及相对同支持最优可行结构误差的距离" | 在**同一活跃集、同一目标质量**下，算出可达的最小结构误差，与 RAVEN 的实际值比较 |
| **S3 必要性（统一预算）** | "在统一信息和调参预算下比较简单目标匹配、匹配加方差、序贯校正及完整 P2" | 列一条"必要性阶梯"，每级给结构端点与代价；对齐贡献归属 |

原文的修复条件同时给了一条**允许的出路**："若收益主要来自简单校准，应据实调整贡献归属"——即这不是必须"证明完整方法更好"，而是**必须给出可比较的阶梯**。

## 2. 论文当前提供了什么（逐条对照）

**已提供**
- **结构端点是主端点**，并有描述性容忍线（表 III、§V、§VII-G）：SensorScope `Δ_group` 从 FedAvg 的 `1.0558` 降到 `1.0139`（`−3.96%`），`Δ_c-s` `1.2903→1.2644`（`−2.01%`）；U-Air 上 Design 以 `RMSE_μ +6.885%` 换 `Δ_c-s −4.990%`。
- **组件边际效应**（Table IV，θ 口径）：Design `−6.943/+4.990/−6.885/−7.221`、Obs `+0.123/+0.022/−0.010/−0.010`、Use `+0.014/−0.014/+0.025/+0.026`、Inst `−0.089/−0.143/+0.143/+0.149`、Debt `+0.004/+0.002/<0.001/<0.001`。
- **代价侧材料已在手但未成表**：P2 求解可行性证据（记录 `X-8`：`778` 警告 / `6438` 窗口 / `2.686e-8` 仅证可行性）、运行时长（City Scanner 每 run `≈38.7 s`）、active-set 守恒核对（774 窗口）。

**已提供、且恰好关掉"预测必要性"这条路（四条独立证据）**
1. **H headroom 不存在**（§VII-F）：预注册 GO 规则未触发；U-Air 全部 `|H| ≤ 0.217%` 且每个 95% 区间含零；SensorScope 在 MDE `0.17–0.36` pp 下六个估计全在 `[−0.03%, +0.08%]`；把观测倾向加硬 `15–21×` 也只到 `0.104%` / `0.251%`。
2. **真实边际本身不带来预测收益**：把一个已校准成员的两个边际换成真值，`RMSE_μ` 只动 `−0.008%`（SS）/`+0.040%`（UA），区间含零。
3. **类别内上界很小**：同类未校准成员 TwoStage-Hájek 高于 oracle 成员 `2.04% [1.33, 2.75]`，其余成员在 SS 全部 `≤0.08%`。
4. **目标图本身不重要**（本轮新增，稿外）：City Scanner 上把 region 权重换成 ACS 人口或 NYC 311，`RMSE_μ` 只动 `≤0.21%`、五臂排序不变；而 Proposition 4 解释了原因——判据只是对**固定**的逐组误差做加权，权重变化不改变误差剖面。

⇒ **推论（本轮评审的关键判断）**：在本 regime 下，"完整方法能在预测端点上更准"这一命题**已被论文自己的测量否定**，因此 W1 的 S3 若按"预测更好"来答，会与稿内证据冲突；W1 必须按**结构 + 代价**来答。

## 3. 缺口具体是什么（可补 vs 不可补）

| 缺口 | 可补性 | 需要什么 |
|---|---|---|
| `Δ_group` 的服务含义与残余量级（S1） | **可补，零新实验** | 一段解释 + 一张"结构错配 ↔ 目标质量缺口"的换算；残余 `1.0139` 与同支持最优的对比（见 S2） |
| 同支持最优结构误差（S2） | **可补，只读** | 用现有工件（`μ`、`α`/`ω`、活跃集）构造"同支持下界"：直接用目标质量作参考、不经过 R/O/U 三层推断的对照；P2 的可行集 `C_r`(25) 已在文中，可据此给数值下界 |
| 统一预算的必要性阶梯（S3） | **大部分可补，且多数级不需要训练** | 现有臂即可排成阶梯：`fedavg_window`（无校正）→ `inst_cal`（瞬时校准）→ `debt_cal`（债务校准）→ `twostage_hajek`（序贯、无 debt）→ `raven_wo_design`（+ P2，无 Design）→ `raven`（完整）。缺的只有最下一级"**直接目标重加权**（跳过三层，直接用 `μ/π̂^opp`）" |
| 最下一级"直接目标重加权"臂 | **需要训练，但便宜** | City Scanner `≈39 s/run`；SensorScope/U-Air 亦可行；这是唯一必须新跑的部分 |
| 贡献归属的据实调整 | **写作决策** | 若阶梯显示简单匹配已拿到大部分结构收益，按 W1 原文调整贡献表述（不影响正确性，但改 originality/significance 的表述） |

## 4. 三档可执行方案（按成本递增）

**W1-a｜只读阶梯 + 同支持下界（1–2 天，零训练）**
- 在**同一活跃集、同一 `μ`、同一 per-seed 配对口径**下重算上述 6 个现有臂的结构端点（`Δ_group`、`Δ_c-s`），输出"必要性阶梯"表；数据源：E2 的 U-Air per-seed 单元（含 block 列）、`post_review/G2_external_baselines/tables/per_seed.csv`（SS/UA，含 on/off）、以及 City Scanner 的 50 个 `CS_ACCEPTED.json`。
- 同支持下界：用 `C_r`(25) 与目标质量构造"参考直接置为 `μ`"的对照，给出结构误差可达下界；把 RAVEN 的值与下界的**差**写成一句话（残余的意义）。
- 代价列：P2 求解可行性证据（`X-8`）、运行时长、维持 active-set 守恒的核对（774 窗口）。
- 产出：一张表 + 一段解释，直接回答 S1/S2/S3（除最下一级）。

**W1-b｜补一级新臂（每个数据块 ≈40 分钟训练）**
- 训练"直接目标重加权"臂（无 R/O/U 三层推断、无 debt、无 P2 方差项），把阶梯的最下一级补齐；在 City Scanner 上代价最小（38.7 s/run × 10 seeds）。
- 风险控制：只作为**对照臂**加入，不进入主表排名的显著性族（或明确标注为阶梯对照）。

**W1-c｜重定位（零新实验，但有代价）**
- 把论文明确重定位为"结构性目标对齐 + 收益上限测量"，用四条证据（H=0、边际无关、类别上界小、目标图无关）说明预测端点在本 regime 不可移动，从而把必要性定义在结构端点与代价上。
- 风险：外部评审的 AC 意见已写"若按分析型论文定位，负面发现的机制和普适性还需更深入"——单独重定位不够，仍需 S2/S3 的阶梯支撑。

## 5. "W1 已闭合"的判据（写成可检验的条件）

1. 稿内出现一张**同支持、同 `μ`、同预算**的表，至少四档：简单目标匹配 / 匹配加方差 / 序贯校正 / 完整 P2+debt；每档给 `Δ_group`、`Δ_c-s` 与代价（求解调用、运行时长）。
2. 明确报告 RAVEN-Design 相对**最强简单基线**（按当前证据是 `debt_cal` 或 `inst_cal`）的结构增益及其配对区间。
3. 给出残余结构误差与**同支持可达下界**的距离（S2）。
4. 若增益低于实践阈值，据实调整贡献归属（W1 原文允许的出路）。
5. 不出现与"预测端点不可移动"冲突的主张（否则与 §VII-F 的四条证据自相矛盾）。

## 6. 与其他开放项的关系

- 与 `M8`（固定活跃集、只切换权重的机制对照）共用同一套只读工件，建议**同轮完成**：`M8` 回答"机制是否唯一"，W1-a 回答"必要性阶梯"。
- 与 `W6`（复现/代表）共用 per-seed 分数与运行时长列。
- 记分影响：Evidence 权重 `0.25` 是当前绝对就绪的瓶颈；W1-a+W1-b 完成后可同时抬升 Evidence 与 Significance（结构收益的**必要性**被量化），并据实处理 Originality 的表述。
