## 一、先把「上限」拆成四层

原文的核心洞见：Tier 2 的「收益不超过 0.03 %」不是一堵墙，而是**四个独立原因叠在一起**。任何一条方法至少要拆掉其中一层。

| 层 | 机制 | 原文依据 / 数字 | 重加权够不够得着 |
|:---|:---|:---|:---|
| **信息层** | 客户端没交付的样本，怎么重加权都补不回来 | T1、T2 | 这是修正族的天花板。**上面还有一层真实空间**：Central-All 比部署方法好 **4.45 %**（SensorScope）与 **5.17 %**（U-Air），只能靠「拿到更多信息」吃到 |
| **端点层** | `μ` 就是测试集份额，所以 `RMSE_μ` 几乎等于合并后的 RMSE，对权重几乎不敏感 | H-B、T4、T5 | 同样的选择偏移下，`RMSE_ρ` 能动 **2.2 %**，`RMSE_μ` 只动 **0.08 %** |
| **学习器层** | 模型接近正确设定，每窗口只有约 **2.45** 个客户端，`local_steps = 2` | T7 第 i 条、T4 | P2 把 `α` 挪动 L1 距离 **0.337**，最终模型几乎不变 |
| **组件层** | 唯一能明显移动结果的组件是 Design，而它在 U-Air 上是**负收益** | T-e、H4 | 丢掉 72 个支撑对，付出 **+6.3 % 到 +7.0 %** 的代价；结构指标上的优势据原文称来自 P2 的校准和 debt，Debt-Cal 就能复现 |

## 二、方法清单（44 条，甲–庚）

### 甲、从「纠正偏差」转到「控制采集」 — 拆**信息层**，上限约为到 Central-All 的差距

| # | 方法 | 要点 |
|--:|:---|:---|
| 1 | 按目标质量空洞派发感知任务 | 把 `ζ` 与 debt 从「聚合权重」改成「任务分配 / 激励」信号，平台主动让客户端去 `π^opp` 低、`π^tar` 高的地方采样。这是 MCS 独有的杠杆，收益上限就是 Central-All 那 4 %–5 % |
| 2 | 按覆盖 debt 选客户端 | 每个窗口优先邀请欠覆盖组的客户端，而不是交付之后再给它们加权 |
| 3 | 客户端内部按目标优先上传 | 带宽或预算受限时，客户端先上传欠覆盖 stratum 的单元，也就是做数据选择 |
| 4 | 控制 `U`：放宽截止时间或重传 | 对欠覆盖组的更新延长 deadline、允许重传，或在低带宽时改传压缩更新，直接提高交付率，而不是事后用 IPW 补偿 |
| 5 | 记住未交付客户端的上次更新 | 参照 MIFA、FedVARP 这类方法，用缓存的更新或 SCAFFOLD 式控制变量补上缺席客户端的贡献，相当于补回「没交付的样本」的一个近似 |
| 6 | 服务器端的代理数据或知识蒸馏 | 若有公开的低精度数据（卫星 AOD、气象再分析数据），就能在空洞处提供弱监督 |
| 7 | 在空洞处用空间插值做伪标签 | 用克里金或图拉普拉斯平滑相邻站点，给未交付的目标单元补伪标签，即半监督 / 转导学习 |
| 8 | 双稳健（AIPW）风险估计 | 用结果模型给未交付单元补预测，再用 IPW 修正残差。从「只加权」走向「加权 + 补值」，能补上纯 IPW 补不上的那部分信息 |

### 乙、换一个对权重敏感的端点 — 拆**端点层**（必须有部署上的理由，并且预注册）

| # | 方法 | 要点 |
|--:|:---|:---|
| 9 | 加权保形预测的覆盖率 | 协变量偏移下不加权的保形区间会系统性低覆盖；按似然比加权（Tibshirani 等，2019）就能修复。`ζ`、`p`、`q` 正是这个方法需要的权重。端点从 RMSE 改成「目标分布下的区间覆盖率 / 区间宽度」，差距通常以百分点计，而不是 0.03 % |
| 10 | 把 RAVEN 定位为目标风险的估计器 | 端点是 `R̂_μ` 与 `R_μ` 之差的绝对值，即模型审计与风险监测。E2 已显示 `RMSE_ρ` 对偏移敏感；在这个问题上权重直接决定估计偏差 |
| 11 | 在目标分布下做模型选择或早停 | 用加权验证集选超参数、选检查点。权重通过「选中哪个模型」间接影响预测，比通过聚合影响大得多 |
| 12 | 外生目标分布，且它与到达分布的总变差距离很大 | 比如按人口、学校、道路重要性加权（D-2、D-3），把 T7 第 ii 条落实。可先报告当前的总变差距离，证明现在的目标分布离到达分布太近 |
| 13 | 决策类端点 | 污染超标告警的 F1、AQI 等级准确率、热点检出率，即 T7 第 iii 条。这类端点对组级误差非常敏感 |
| 14 | 组级尾部风险 | 各组 RMSE 的 CVaR、最差 k 个站点的误差、空洞区域专项 RMSE。收益集中的地方在这些指标上不会被平均掉 |
| 15 | 报告「收益占可恢复差距的比例」 | 即关掉了 Delivered→All 差距的百分之多少，或离 oracle 还有多远。不抬高上限，但能把 0.03 % 放回正确的分母里 |

### 丙、让学习器对权重敏感 — 拆**学习器层**

| # | 方法 | 要点 |
|--:|:---|:---|
| 16 | 沿偏移方向的模型误设定 | T7 第 i 条。C3 失败是因为昼夜信号本来就弱；应改成限制空间容量（小嵌入维度、站点共享嵌入），或用线性 / 低秩模型。容量不够时，权重决定模型把能力花在哪里 |
| 17 | stratum 之间存在条件分布差异，而模型看不到 stratum | 比如各设备的校准漂移不同，这时权重决定折中点落在哪里 |
| 18 | 增大本地步数与客户端异质性 | 依 FedNova 的「目标不一致性」，本地步数大时聚合权重决定收敛的平稳点；`local_steps = 2` 会把这个效应压没 |
| 19 | 有限轮数或随时停止的场景 | 端点改成学习曲线下的面积，或达到目标风险所需的轮数。权重影响的是「先学到什么」 |
| 20 | 个性化或多任务 | 共享表示加分组输出头时，权重决定共享表示偏向谁 |
| 21 | 按目标权重组合分组专家 | 训练多个分组专家，预测时按目标分布组合，相当于把重加权搬到预测阶段 |
| 22 | 服务器端按目标权重做事后校准 | 在全局模型上加一个分组偏置校正，用目标加权的残差来估。RMSE 对系统性偏差很敏感，这一步能直接改变组级误差 |

### 丁、让选择偏差本身足够大 — H-C：现实的倾向更难

| # | 方法 | 要点 |
|--:|:---|:---|
| 23 | 非随机缺失（MNAR） | 高污染或高温时传感器更容易失效、电池更快耗尽，选择就和 `y` 相关。这时基于 `x` 的 IPW 修不了，需要影子变量、模式混合模型等新组件。偏差大，空间也就大 |
| 24 | `U` 与标签相关 | 比如交通高峰时网络拥塞，更新更容易丢失，`U` 的缺失就和 `y` 相关 |
| 25 | 单元级、异质、偶尔为零的倾向 | F-1 的方向：把倾向移到 stratum 内部之后，精确倾向的价值放大了 **15–21 倍**，只是绝对值还不够。可沿此继续加强，再配上外生目标 |
| 26 | 更多带实测选择机制 `R` 的数据块 | T7 指出，方法间差距超过 1 % 的只有 `R` 是真实的块（T-Drive **1.6 %**、Pilot 2 约 **1.2 %**）。优先找有真实设备日志、真实连接日志的数据 |
| 27 | 策略性参与 | 客户端按激励或自身损失决定什么时候参与，选择和本地损失相关 |
| 28 | 目标分布随时间漂移 | 权重必须跟着变，不加权的方法会跟不上。仓库里已有 `e3_drifting` 目录可以借用 |

### 戊、换修正算子本身 — 在「标量聚合权重」之外

| # | 方法 | 要点 |
|--:|:---|:---|
| 29 | 单元级密度比 | 用 KLIEP 或分类器估计的密度比替代 stratum 常数权重，让 Hájek 在客户端内部的权重不再是均匀的；目前实现出来的权重恰好均匀 |
| 30 | 把修正搬到本地损失里 | 样本级加权比参数平均时的聚合加权对最终模型的影响大得多，这正好回应 T4 |
| 31 | 损失感知的 P2 | 现在的 P2 只匹配质量构成 `Mα ≈ μ`。改成按客户端梯度与「目标风险梯度」的对齐程度来定权重，类似 learning-to-reweight（L2RW）或 FedLAW 的可学习聚合权重 |
| 32 | 用倾向的不确定性构造 group DRO 的不确定集 | 直接优化最差组的风险 |
| 33 | 降低方差的权重形式 | 稳定化权重、overlap 权重、自适应截断、控制变量。IPW 的收益可能被方差吃掉了 |
| 34 | 表示对齐 | 在重要性加权之外，再做到达分布与目标分布之间的特征匹配（域适应） |
| 35 | 在服务器上对全局模型做目标加权微调 | 用已交付数据按目标权重再做几步训练 |

### 己、把 Design 的代价变成收益 — 拆**组件层**

| # | 方法 | 要点 |
|--:|:---|:---|
| 36 | 温和化的 Design | 用 `ζ^γ`（`γ ∈ [0,1]`），或给 `ζ` 设下限 `ε > 0`，让 `π^tar = 0` 的对保留一点权重。Design 与 NoDesign 是 `γ = 1` 和 `γ = 0` 两个端点；中间某个值可能同时拿到 `Δ_c-s` 的收益，又避开 7 % 的代价 |
| 37 | 平滑 `π^tar` | 空洞来自测试集份额的离散零点。用相邻 stratum 或时间块做核平滑、拉普拉斯平滑，零点就消失了，也顺带缓解 P-a |
| 38 | 把 Design 只放进 P2 的组项，不放进本地损失 | 这样拆开「支撑丢失」与「构成校准」两个作用 |
| 39 | 在 Design 与 NoDesign 之间做模型平均或门控 | 按组或按窗口选择，或者对两者的预测加权 |
| 40 | 把 Design 的信息从「丢数据」改成「调度」 | 即甲组第 1、2 条：空洞处不丢数据，而是去补采 |

### 庚、正对照与理论 — 证明方法在该起作用时确实起作用

| # | 方法 | 要点 |
|--:|:---|:---|
| 41 | 预注册的正对照数据块 | 在半合成数据上同时满足三个条件：沿偏移方向的误设定、较大的总变差距离、按目标分布评估。先证明 RAVEN 在理论上应该赢的地方确实能赢超过 0.5 %，再说明真实数据块为什么不满足这些条件 |
| 42 | 给出收益的解析上界 | 比如证明收益受「目标与到达分布的总变差距离 × 条件风险的离散度」约束，在现有数据块上算出这个上界。这会把「收益小」从「方法不行」变成「问题本身的空间小」，是可以发表的结论 |
| 43 | 半合成重打标签 | 保留真实的特征和选择机制，按 stratum 注入不同的条件分布，从而控制空间的大小 |
| 44 | 扫描空间大小，画相图 | 横轴是误设定强度与总变差距离，纵轴是 RAVEN 的收益，标出越过 0.5 % 的区域 |

## 四、原文单列的一条风险

**乙组的方法都是在看到结果之后换端点。** 审稿人很容易把它读成「移动球门」。要避免这一点，端点必须有**独立的部署依据**（比如告警决策、区间覆盖率本身就是 MCS 的需求），并且在跑之前**预注册**。

**甲组和己组则会改变方法本身**，更接近写一篇新论文，而不只是修订这一篇。
