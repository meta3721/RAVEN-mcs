R1c-A.2 建立唯一 frozen atomic target law
------------------------------------------------------------

论文要求：

  varpi_i^{tar}

是唯一 atomic deployment law。

然后所有 target object 必须从它派生：

  mu_g
  =
  sum_{i:h(i)=g} varpi_i^{tar}

以及 client-stratum target：

  pi^{tar}_{k,s}
  =
  sum_{i:s(i)=s}
    xi_{k|i}^{tar}
    varpi_i^{tar}

若当前方法存在 frozen/public client allocation rule xi，
使用已有规则。

如果 pi_tar 的定义不是上述分解形式，
应按照 PostAudit Sections III--VI 的正式定义实现，
但不得引入 test outcome。

要求：
  varpi_tar 的来源必须是 public/frozen target specification，
  不能通过 test Y / test prediction residual 得到。

------------------------------------------------------------
R1c-A.3 兼容性等式必须数值验证
------------------------------------------------------------

  TARGET_COMPATIBILITY_CHECK.csv

至少检查：

A. 总质量：
  sum_i varpi_tar(i) = 1

B. group marginal：
  for every g:
    mu_g
    ==
    sum_{i:h(i)=g} varpi_tar(i)

C. client-stratum total：
  sum_{k,s} pi_tar(k,s) = 1

D. group bridge：
  对每个 g：

    mu_from_pi(g)
    =
    sum_{k,s}
      pi_tar(k,s)
      * 1{ h(s) = g }

============================================================
七、R1c-C：重新构造 opportunity-support LCB
============================================================

当前失败的 estimator：
  对 window-level normalized pair mass x_t 使用 EB：

    x_bar
    -
    sqrt(2 v log(1/delta)/n)
    -
    3 log(1/delta)/n

在 n<=32 时下界几乎必然截为 0。

禁止继续用这个退化 estimator 作为主 C_cov certifier。

本轮优先采用：
  COMPLETED EVENT-COUNT AGGREGATION
  + one-sided lower confidence bound。

------------------------------------------------------------
R1c-C.1 累积 completed opportunity counts
------------------------------------------------------------

对 current window r，
只使用 t<r 的 completed windows。

对每个 (k,s)：

  C_{k,s,r}^{opp}
  =
  sum_{t in H_r}
    N_{k,s,t}^{opp}

总 completed events：

  C_{r}^{tot}
  =
  sum_{k,s}
    C_{k,s,r}^{opp}

其中 H_r 是冻结的 lookback policy。

先不要自动限制为旧的 32 个 normalized-mass samples。
要审计：
  32 windows 内一共有多少 opportunity EVENTS。

如果每 window 有大量 events，
event-count sample size 可以远大于 32。

输出：

  EVENT_COUNT_EFFECTIVE_SAMPLE.csv

字段：
  dataset
  seed
  window
  history_windows
  total_completed_events
  target_positive_pairs
  min_pair_count
  median_pair_count
  max_pair_count

------------------------------------------------------------
R1c-C.2 主推荐方案：count-based one-sided bound
------------------------------------------------------------

如果当前 opportunity model 可把 completed opportunity events
作为对 frozen event-mark law 的可交换/条件 multinomial samples，
则对每个 pair 使用 one-sided binomial marginal lower bound。

优先实现：

  one-sided Clopper-Pearson lower bound

对于：

  x = C_{k,s,r}^{opp}
  n = C_r^{tot}

求：

  lower_pi_opp(k,s,r)

满足 one-sided confidence level。

重要：
  若需要 simultaneous multi-pair coverage，
  不得把 per-pair 95% 直接称为 family-wise 95%。

可选择：

A. Bonferroni-adjusted pairwise one-sided bounds：
   delta_pair = delta_cov / m_target_positive

或

B. 先做开发 calibration，
   将 pairwise nominal level 校准到 empirical joint coverage。

优先 A，简单且可复算。

但如果 m 很大导致 A 又全部归零，
不要私自换成宽松 nominal level；
先输出诊断。

------------------------------------------------------------
R1c-C.3 若 event independence/exchangeability 不成立
------------------------------------------------------------

如果代码/数据生成机制无法支持 event-level multinomial/binomial解释，
禁止硬用 Clopper-Pearson 并声称 exact。

此时采用：

  completed-window BLOCK calibration

例如：
  - block bootstrap one-sided lower quantile；
  - conformal/calibrated lower bound；
  - window-cluster conservative bound。

但必须：

  strictly t<r；
  不用 current R；
  可复算；
  报 empirical held-out coverage；
  不声称 exact iid confidence bound。

报告必须明确选了哪条路线以及适用假设。

------------------------------------------------------------
R1c-C.4 C_cov 定义保持不变
------------------------------------------------------------

无论用何种 lower_pi：

  C_cov_LCB(r)
  =
  sum_{k,s}
    pi_tar(k,s)
    1{
      lower_pi_opp(k,s,r) >= pi_safe
    }

不得改公式。

------------------------------------------------------------
R1c-C.5 support certificate calibration
------------------------------------------------------------

post-window 仅用于 audit：

定义 realized/reference opportunity mass：

  pi_opp_ref(k,s,r)

必须由合法 held-out/completed audit protocol构造，
不能用于 current Gate。

检查：

  pair_covered
  =
  1{
    lower_pi_opp(k,s,r)
    <=
    pi_opp_ref(k,s,r)
  }

报告：

  pairwise coverage
  target-mass-weighted coverage
  joint-window coverage
  mean/median LCB slack
  certified target mass

注意：
  C_cov diagnostics 不是 Theorem 4 的唯一安全依据，
  但必须证明它不是严重 anti-conservative。
