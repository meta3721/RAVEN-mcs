Recoverable-Gain Ceiling Only the part of the prediction error that a selection-aware reweighting could remove in principle is reachable by any correction in this family. We measure that part by replacing the estimated propensities with their true values and reporting X over a stress grid that varies the opportunity tilt, the tail observation scale, the model capacity and the target. The GO rule was frozen before the runs: GO if any condition reaches X with a positive interval lower bound. It did not fire. SensorScope is conclusive at a paired-difference minimum detectable effect of X--X percentage points, with all six estimates inside X. U-Air was re-run at X seeds, X runs and X regenerated traces, where every estimate satisfies X and every X interval contains zero. Its realized detectable effect is X--X points, so that block excludes effects above about X and does not resolve the X bar on its own. Hardening the observation propensity to vary within a stratum and to correlate with the label raises the oracle gap by X--X, to X on SensorScope and X on U-Air, both inside the same bound. The ceiling is therefore a property of these endpoints rather than of a regime that was made too easy, and it bounds what any later claim about the correction family can reach on these blocks.
