## 1. 档位定义（Phase 4 原文转录）

统一条件：同一尺子、同一活跃集、同一 `μ`、同一 `β̂_r`；逐窗口求 `α_r`，再算两个结构端点。
凡用 debt 的档位，按该档自己的 `α` 递推 `Q_{r+1} = [Q_r + η(μ − M_r α_r)]_+`，`η` 取运行配置值。

| 档 | 名称 | 定义 | 调参网格（7 点） | 精确性 |
|---|---|---|---|---|
| L0 | Uniform | `α = 1/K` | 无 | 精确 |
| L1 | Count | `α ∝ raw_counts`，再欧氏投影到 `C_r` | 无 | 精确 |
| L2 | 直接目标重加权 | `ρ̂_g = Σ_k m_k c_{g,k} / Σ_k m_k`；`α_k ∝ m_k Σ_g c_{g,k} μ_g / max(ρ̂_g, ρ_min)`，再欧氏投影到 `C_r` | `ρ_min ∈ {1e-4, 3e-4, 1e-3, 3e-3, 1e-2, 3e-2, 1e-1}` | 精确 |
| L3 | 目标匹配 | `argmin_{C_r} ½‖M_r α − μ‖² + ½ε‖α − β̂_r‖²` | `ε ∈ {1e-8, 1e-6, 1e-4, 1e-3, 1e-2, 1e-1, 1}` | 精确 |
| L4 | 匹配 + 方差 | L3 + `½λ_v αᵀV_rα` | `λ_v ∈ {0.01, 0.03, 0.1, 0.3, 1, 3, 10}`，`ε` 固定为 L3 选中值 | V 来自所复现臂轨迹，标 `open_loop_V` |
| L5 | 完整瞬时 P2（= Inst-Cal 目标） | `solve_p2(..., debt=0)`，冻结 λ | `λ_g ∈ {1, 1.5, 2, 3, 5, 8, 13}`，其余冻结 | 用 `inst_cal` 自己的 V 时精确 |
| L6 | P2 + debt（= RAVEN） | `solve_p2(..., debt=Q_r)`，冻结 λ | 同 L5 | 用 `raven` 自己的 V 时精确 |
| L4′ | 序贯 debt 匹配 | `argmin_{C_r} −Q_rᵀM_r α + ½‖M_r α − μ‖² + ½·1e-8‖α − β̂_r‖²` | `λ_g` 同 L5 | 精确 |

- `m_k` 取 `total_masses`，`c_{g,k}` 取 `M_r` 第 k 列。
- L5、L6 各算 7 个配置，冻结默认值是其中一点 ⇒ 各档调参预算相同，冻结的完整方法无额外优待。
- L0、L1 无超参数，报告时标 `budget=0`。

## 3. 主判据与阈值

| 量 | 值 | 含义 |
|---|---|---|
| `τ_near` | `0.80` | `G` 的配对 95% 区间下界 ≥ 0.80 才可称"接近同支持最优" |
| `τ_eq` | `0.10` | 两档 `G` 之差的配对区间完全落在 `[−0.10, 0.10]` 内，才可称"等效" |
| 必要性方向 | `+0.10` | 两档之差配对区间完全在 `+0.10` 以上，才可称"更强档必要" |

判定表（机械套用，不另作解释）：

| 结果 | 允许写的结论 |
|---|---|
| L6 − L5 ∈ [−τ_eq, +τ_eq] | debt 对结构端点无独立贡献；debt 只保留为可审计记账 |
| L5 − L3 或 L5 − L2 ∈ [−τ_eq, +τ_eq] | 结构收益来自"在 `C_r` 内做目标匹配"；P2 其余项非必要 |
| L5 的 `G` 下界 ≥ τ_near 且 L5 − 最强简单档区间整体 > +τ_eq | 完整 P2 必要且接近同支持最优 |
| 以上都不满足 | 写"结果不足以区分"，给区间，不选边 |

## 4. 统计方法

- 逐种子配对差；**bootstrap 10 000 次，种子 `20261002`**，取百分位区间；同时报告 Wilcoxon 符号秩检验 p 值。
- Holm 校正家族 = **每个数据集 × 每个端点 × 下列 L-对比**（完整枚举）：
  1. `L6 − L5`；2. `L5 − L3`；3. `L3 − L2`；4. `L5 − L4′`；5. `L6 − 最强 L0–L4′`。
  端点为 `Δ_group` 与 `Δ_c-s`；数据集为 SensorScope 与 U-Air ⇒ 家族内共 **2 × 2 × 5 = 20** 个检验。
- 最强简单档 = `L0–L4′` 中在**调参种子**上 `Δ_group` 均值最小的那一档，报告时固定不再变。

## 6. 其他冻结项

- 求解器：CLARABEL，容差 `1e-6`；`ᾱ_r, Ē_r` 用 `raven_mcs.aggregation.feasibility`，`e_min = min(3, K_r)`。
- 尺子：`R_on`（Design-on，来自 OBSERVED E4 arms 的 `M` 与 `w`）、`R_offp`（来自 `raven_wo_design`）、`R_raw`（纯计数，Phase 2 后才有）。
- `Δ*` 的定义（写进报告）："在相同活跃集、相同组成 `M_r`、相同可行集 `C_r`，且事先知道全部窗口时，结构误差的最小值"；它不是对其他目标图、其他信息集或其他活跃集的下界；Design-on 与 Design-off 必须分尺子各算一次。
- `G_F(rule) = (Δ_F(unif) − Δ_F(rule)) / (Δ_F(unif) − Δ*_F)`，锚点 `α_r = 1/K_r`；分母 `< 1e-6` 记 `NA_degenerate`。
- `headroom_debt = Δ_myo − Δ*`，其中 `Δ_myo` 为逐窗口独立最优（**不是**在线规则的下界）。
- 输出目录：`results_w1_ladder/round_v1/`；脚本：`scripts/w1_capture.py`、`scripts/w1_replay.py`。
- 禁止写的结论：见协议「禁止写的结论」全部 8 条（含不得声称 `RMSE_μ`/WorstGroupRMSE 更优、不得把 `Δ*` 推广到其他尺子、不得把不同尺子的 `Δ_group` 直接相减、不得称 Inst-Cal 为"简单校准"、不得称 `Δ_myo` 为下界、报告种子不得重选、门失败不得放宽容差、L4 开环不得写成与 L5/L6 同等精确）。
