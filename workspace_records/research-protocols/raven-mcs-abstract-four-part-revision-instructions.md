当前读取到的摘要按该统一函数为 **169 词元**；原始 TeX 按空格统计为 166，两者口径不同。执行时重新冻结 W0；不要把二者交叉比较。

可使用以下函数，输入为 abstract 环境内部的正文，不含环境命令：

```python
import re

def abstract_word_count(abstract):
    text = re.sub(r'(?m)(?<!\\)%.*$', '', abstract)
    text = re.sub(
        r'\\(?:label|cite[a-zA-Z]*|ref|eqref|autoref|cref|Cref)\*?'
        r'(?:\[[^\]]*\])*\{[^{}]*\}', ' ', text)
    text = re.sub(r'\$[^$]*\$', ' ', text)
    text = re.sub(r'\\(?:begin|end)\{[^{}]*\}', ' ', text)
    text = re.sub(r'\\[A-Za-z]+\*?(?:\[[^\]]*\])?', ' ', text)
    text = text.replace('\\', ' ').replace('{', ' ').replace('}', ' ').replace('~', ' ')
    return len(re.findall(r"[A-Za-z0-9]+(?:[-’'][A-Za-z0-9]+)*", text))
```

### 第三部分：现有研究状况——恰好一句话

概括相关研究已在客户端参与校正和目标组成匹配方面取得进展，再说明这些进展与原子感知单元校正到当窗受约束执行的联系仍需研究。

### 第四部分：本文方法——按下面四步顺序展开

**1. 提出了什么方法——恰好一句话。**

使用 `We propose RAVEN-MCS, ...` 或同等直接句式，说明核心动作：重构原子感知单元目标参考，并将其转成有限窗口内可执行的客户端权重。

不加入未经支持的 first、universally optimal、guaranteed accuracy improvement 等主张。当前简称可直接使用，不为了形式强塞过长全称。

**2. 具体来说——用一至两句解释方法细节。**

用 `Specifically, ...` 或自然递进，交代顺序校正和可行校准之间的机制联系：参考质量如何得到，硬权重上限和有效支持约束如何限制聚合，参考保真、组组成和欠服务状态如何协调。

重点说明方法为什么能处理所述缺口，不重复提出方法句，不把具体实现配置、所有正则项或公式塞入摘要。必要时选取最能说明创新的机制，不要求列全算法变量。

**3. 理论分析证明了什么——恰好一句话。**

以 `Our theoretical analysis establishes ...` 或同等句式，概括已有核心结果，优先保留理想矩恢复及固定窗口状态的校准稳定性。

按所选结论保留必要条件，包括理想比率、兼容支持、顺序识别、聚类正则性，以及校准稳定性的固定状态范围。不要把不适用的条件混为所有结论的共同前提。

不要求在一句话内列完全文所有定理。涉及长期对齐时必须保留次线性债务条件；若篇幅不足，宁可不概括长期性质，也不能改成无条件长期保证。不暗示理论已证明普遍 RMSE 改善。

**4. 实验结果表明了什么——恰好一句话，作为摘要最后一句。**

集中报告两个 City Scanner 主协议中，完整 RAVEN 在五方法比较里的平均组失配优势；保留相对 TwoStage-Hájek 的 **25.8%、23.3%** 下降。

这两个数字属于 group mismatch，不是 RMSE；来自两个协议而不是单一协议的区间。使用原有证据口径，不能根据四舍五入的表格均值重算百分比。

在同一句中保持合理范围，例如 real sensing opportunities and controlled delivery，不能声称真实端到端联邦交付部署。两项协议的 O 控制/测量区别可以在这句话中简洁交代，或由正文设置完整说明，但摘要不能暗示所有选择层均为真实测量。

不加第二句“实验还发现……”或另起 matched-support 结果句；若需体现归因价值，应在方法细节中准确说明比较目的，或者在这一实验句中合并必要含义。摘要尾部不追加贡献列表、未来工作或泛化总结。
