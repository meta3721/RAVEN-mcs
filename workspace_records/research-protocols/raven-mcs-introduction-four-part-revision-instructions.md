## 2. 冻结修改前词数

以执行时当前引言为基准，先得到 W0，再修改，最后计算 W1。要求 W1 = W0，不采用默认减少 10% 或 ±5% 的宽松标准，不用与前几天旧稿相比较。

固定统计口径：仅统计引言正文的英文词元；不含章节标题、LaTeX 命令、label、文献编号、交叉引用编号和行内数学；连字符连接的术语按一个词元计，前后使用完全相同程序。

可使用下面的非变更计数函数，直接在读取的引言字符串上计算，不需要生成额外脚本文件：

```python
import re

def introduction_word_count(intro):
    text = re.sub(r'(?m)(?<!\\)%.*$', '', intro)
    text = re.sub(
        r'\\(?:label|cite[a-zA-Z]*|ref|eqref|autoref|cref|Cref)\*?'
        r'(?:\[[^\]]*\])*\{[^{}]*\}', ' ', text)
    text = re.sub(r'\$[^$]*\$', ' ', text)
    text = re.sub(r'\\(?:begin|end)\{[^{}]*\}', ' ', text)
    text = re.sub(r'\\[A-Za-z]+\*?(?:\[[^\]]*\])?', ' ', text)
    text = text.replace('\\', ' ').replace('{', ' ').replace('}', ' ').replace('~', ' ')
    return len(re.findall(r"[A-Za-z0-9]+(?:[-’'][A-Za-z0-9]+)*", text))
```

其中 intro 为两个 section 命令之间的内容，不包含这两个 section 标题。2026-10-30 本次审查时，该口径为 481 词元，仅作定位参考；如执行时稿件已经变化，以重新冻结的 W0 为准。不要混用原始 TeX 按空格统计数与正文词数。

## 3. 严格采用以下唯一叙事顺序

修改后的引言只有四个逻辑部分，依次为：

### 第一部分：研究背景——恰好一句话

用一句英语概括移动群智感知的数据稀疏性、数据补全需求及联邦学习的场景意义，保留必要的背景文献。

这句话只回答“研究什么、为什么需要研究”，不提前展开具体缺口、方法细节或实验结果。不用空泛的重要性套话，不用多个分号将整段背景伪装成一句。

### 第二部分：存在的问题——恰好一句话

用一句英语交代本研究要解决的具体问题：感知机会、实际观测、可用交付的选择改变更新代表性，而校正后的目标参考仍不一定能在当窗支持、权重上限和有效支持约束下执行。

将选择偏差与可执行混合之间的逻辑连起来，不能只说“数据非独立同分布”“现有方法性能不足”等笼统问题。

这一句不评价实验表现，不使用图表编号，也不要在后面的现状句之后再次另起问题段打乱顺序。

### 第三部分：现有研究状况——恰好一句话

用一句英语概括参与偏差校正和目标感知聚合的相关进展，准确承认 FedIPW、FedPALS 等工作解决的对象，同时自然指出它们与本文原子感知单元到受约束当窗混合的研究对象之区别。

使用已有已核实引用，不新增未经检索的论文，不把别人已经做过的目标匹配说成研究空白。详细综述仍在 Related Work，不在这一句话中排队介绍大量方法。

### 第四部分：本文方法——严格按下列四步展开

**4.1 提出了什么方法——恰好一句话。**

以 “We propose RAVEN-MCS …” 或同等直接句式，给出方法名称、核心思路及解决对象：重构原子感知单元目标参考，并将它转成有限窗口内可执行的客户端聚合权重。

不要用“提出一个新颖、全面、先进的框架”代替机制，也不要在方法提出句中提前报告实验效果。

**4.2 具体来说——方法细节，承担主要篇幅。**

用 “Specifically, …” 自然接入，可以写若干连贯段落和正常长度的句子，不限制为一句。按实际执行链展开：

- R/O/U 的层次和各自信息边界，机会与观测校正如何进入归一化局部训练及参考质量。
- 可用更新校正如何形成客户端参考分布，而不是把参考权重直接当成可执行权重。
- 可行校准如何在当窗支持、客户端权重上限及有效支持约束下兼顾参考保真与部署组组成。
- 债务如何记录跨窗口欠服务，方差和陈旧度代理如何进入选择，Design 与诊断 Gate 如何保持各自身份。

篇幅用于解释机制、相对已有研究的实质区别和步骤之间的因果联系，不能塞入参数配置、实验数字、长公式或内部开发历史。已有正文后续章节会给出正式定义，引言不用重复完整推导。

如果保留导师要求的 1、2、3 编号创新点，将它们融合在这一方法细节块内，分别表达已有的研究贡献，不再在实验结果句后追加独立的 “Our contributions are” 列表。不能把原有实验评价贡献伪装成新算法模块，也不能将同一机制换三个标题重复介绍。以本次四部分顺序和准确表达为优先；不为形式增加不存在的创新。

**4.3 理论分析证明了什么——恰好一句话。**

以 “Our theoretical analysis establishes …” 或同等句式，集中概括已有理论结论，并保留使其成立的必要范围：理想矩恢复、可行校准的存在唯一性及固定窗口状态下的参考扰动稳定性；涉及长期对齐时，必须保留债务次线性增长条件。

可以根据主要贡献选择准确的核心结论，不要求将全文每个定理塞进一句话；不能删掉必要条件以换取通顺，也不能把固定状态性质改成无条件动态收敛。句子中的合理并列不等于可以写成几行长的分号串。

**4.4 实验结果表明了什么——恰好一句话，作为引言最后一句。**

依据现有两个 City Scanner 主协议，概括完整 RAVEN 在五方法比较中的平均组失配优势，并可保留相对 TwoStage-Hájek 的 25.8%、23.3% 下降。准确说明这是 group mismatch 端点，不是 RMSE 改善。

一句话中保留必要的协议范围，例如真实感知机会、受控制交付；不得写成真实端到端部署验证。不要将该结论扩展成所有数据集或全部预测端点普遍领先，不加入未成立的非劣性、零开销或无精度损失结论。

不写 Table/Fig. 编号，不追加第二句结果解释，不在这一句之后再放贡献列表、文章安排或额外总结。详细证据留在 Evaluation。

## 4. 如何在不改变总词数的前提下重排

1. 先压缩前三部分：每部分各一句，不把原来多个背景、问题、综述段落原样保留。
2. 将原方法介绍和贡献条目合并去重，增加机制之间的必要解释，使第四部分承载大部分篇幅。
3. 将原来分散的理论概括合为一个准确句子，将验证安排改为最后一个实验结果句。
4. 计算 W1 与 W0 的差。若偏长，优先删重复解释及修饰；若偏短，补足现有方法中真实但未解释清楚的机制联系。不要从实验节搬入结果细节，也不要堆砌“important/novel/comprehensive”等词补数。
5. 用局部措辞调整达到 W1 = W0，同时人工检查语言自然度。不能添加无意义同义句、隐藏注释或机械连词来凑计数，也不把内容挪到脚注逃避统计。
6. 本轮不得通过删除所需引用导致全篇近年文献计数回退。先将已有相关引用合理合并到前三句或合适的方法说明；不要增加无关引文。

## 5. 修改后逐项核验

- 顺序只能是：背景 → 问题 → 现状 → 本文方法；不可恢复为常见的“背景—现状—问题—方法”。
- 前三部分各一句；第四部分的方法提出、理论分析和实验结果也各一句，方法细节可多句。
- 理论句在方法细节之后，唯一实验结果句在理论句之后且为引言末句。
- 没有独立追加的贡献段或文章结构段破坏指定顺序。必要的编号贡献已融合进方法细节。
- 引言没有图表浮动体、图表编号引用或其他实验结果句；图 1 仍在第三节。
- 引言中的理论结论、方法身份、R/O/U 信息边界、Design/Gate 关系与正文一致。
- 25.8%、23.3% 的比较对象、指标和协议范围准确；不依据表格四舍五入值重新计算。
- W1 = W0，同一口径统计，附上修改前后计数和分部分计数。
- 引言之外的摘要、图表、实验数值、公式、定理及参考文献元数据没有未经授权变化。
- 编译 main 和必要的 supplemental 引用链，检查无未定义引用及标签问题，版面无重叠和溢出；保持正文不超过 14 页、补充不长于正文。

本次四部分结构应直接体现在英文段落和过渡中，不在正式引言中加入“Research Background / Existing Problems / Current Research / Our Method”之类模板小标题。
