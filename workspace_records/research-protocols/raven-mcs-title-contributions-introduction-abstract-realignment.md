## 五、按指定八句模板重写摘要

### 13. 总体要求

一个连续英文段落，严格八句话，建议约180–220词；若科学含义需要可略作调整，但不得明显拖长。拼写使用 `However`、`Existing`、`Furthermore`、`experiments`，不要保留用户消息中的拼写或编码异常。

不添加图表引用、参考文献、列表、内部阶段编号。八句必须与重新凝练的三项贡献和标题保持同一研究对象。

### 14. 八句的固定角色与句首

**第1句：背景。**

以 `Mobile crowdsensing completion ...` 开头。说明从分布式稀疏观测重构城市/环境场的任务价值，不把“补全”写成新增测量或保证完整真实覆盖。

**第2句：问题。**

以 `However, ...` 开头。说明顺序选择造成代表质量偏离，且有限窗口使校正参考与可执行聚合之间出现缺口。表达两个相关问题，避免塞入全部符号。

**第3句：现有研究。**

以 `Existing approaches ...` 开头。准确概括现有方法在补全、参与校正或目标聚合上的能力，并指出本文要连接的感知单元重构与约束窗口执行问题。

不能绝对声称所有前作只做一层选择、都没有目标校准或都没有ESS；具体缺口保持在本文讨论的对象交集。

**第4句：框架。**

采用以下句式，括号只开闭一次：

`To bridge this gap, we propose RAVEN-MCS (Reference Alignment Via Exposure-aware Normalization for Mobile CrowdSensing), an integrated framework that ... .`

后半句一句概括“感知单元目标参考重构到有限窗口可执行客户端混合”的连接。

**第5句：机制第一步。**

以 `Specifically, ...` 开头。说明机会/观测校正如何同时形成局部归一化训练与客户端参考质量。

**第6句：机制第二步。**

承接第5句，可以 `The framework then ...` 或 `Building on this reference, ...` 开头，不必生硬重复 Specifically。说明可用性校正与cap/有效支持约束下的组目标校准，必要时简述累计欠服务。

第5、6句合计构成用户要求的两句方法过程，不再拆出第9句。

**第7句：理论。**

必须以 `Rigorous theoretical analysis validates ...` 开头。明确对象：在所述识别/支持条件下的理想目标矩恢复，以及固定共享窗口状态下的可行校准性质或参考扰动非扩张。

只选择最能突出贡献且确实证明的结果，避免罗列所有定理。不能写成保证神经网络无偏、端到端收敛、任意缺失支持恢复或无条件队列稳定。

**第8句：综合实验结论。**

必须以 `Extensive experiments on real-world datasets demonstrate that ...` 开头。

综合两个层面的证据：

1. 两套城市感知协议中的部署组质量对齐收益。
2. 站点数据的匹配支持比较与支持几何分析，分别刻画参考校正、可行投影及可调整空间。

这句不能只写“在City Scanner上降低25.8%和23.3%”，但也不能把该收益推广为所有数据集的普遍提升。可用“两套城市感知协议”的准确范围表达应用收益，再用同一句的并列分句概括跨实验的机制发现。

### 15. 第8句的证据核对要求

核对下列现有事实后再综合，不能凭泛化措辞跨过差异：
