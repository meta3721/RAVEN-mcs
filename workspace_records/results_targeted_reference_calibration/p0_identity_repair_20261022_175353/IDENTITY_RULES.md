# 参考记录身份规则

本文件只定义行级联结。它没有被用来生成评价面板，也没有被用来拟合模型。日期窗、West/North、5% 收益门槛和 2% 组差保护都没有改。

旧目录 `p0_p1_20261022_161223` 的 `INVALID_RUN` 保持原样。

## 旧键为什么不完整

旧键是站点 + 日期 + `FEMorFRMtype`。补充表 S4、S5 已经写出同一站点、同一型号可以有多个 POC，但这两张表没有给 381 个冲突键逐行指定 POC。EPA 日汇总用站点、参数和 POC 区分监测序列；同一监测器还可能因采样时长、污染物标准和事件处理各有一行。依据是 [FileFormats.html 第 1.1、1.2 和 5.1 节](https://aqs.epa.gov/aqsweb/airdata/FileFormats.html)。

因此，同一旧键下两个不同的 `PM25FM` 不能直接写成原始数据错误，也不能保留第一条、按与传感器的接近程度挑选，或取平均。

## 拟议事件键

只在下面三条同时成立时，一行才算连到唯一监测记录：

1. 参数是 `88101`。这是 PM2.5 FRM/FEM。可接受 PM2.5 的 `88502` 只用来检查未命中的行，不用它替换 FRM/FEM。
2. EPA `Method Name` 与源行 `FEMorFRMtype` 完全相同。这是源行已有的方法字段，对应 FileFormats 日汇总第 22 列。
3. EPA `Arithmetic Mean` 与 `PM25FM` 按十进制精确相等。用的是日汇总第 17 列，不是 `1st Max Value`。不设“更接近”的容差。

采样时长按仪器类型固定，不按数值好坏选择：

- 重力法 FRM（`R & P Model 2025` 连续采样器）用 `24 HOUR`。FileFormats 5.1 第 2 点：一日一张滤膜时，日均值等于该样品。匹配行的观测次数是 1，均值等于当日最大值。
- 连续 FEM（BAM-1020、BAM-1022、T640）用 `1 HOUR` 的日算术平均。FileFormats 5.1 第 1 点：这是亚日样本的日汇总。匹配行的观测次数是 24。`24-HR BLK AVG` 是另一条计算时长；它和 `1 HOUR` 均值可以不同，例如 2019-01-27 的 BAM-1022 小时均值 11.541667 对应块平均 11.5。两者不相等时不合并，也不平均。

同一 POC、同一方法、同一事件类型、同一时长、同一均值若只因 `Pollutant Standard` 重复，合并为一条。FileFormats 1.2 和 5.1 说明标准不同会重复同一汇总。合并的前提是均值已经相同，不是把不同浓度平均成一个数。

事件类型保留在键里。FileFormats 第 14 列说明例外事件可以让同一监测器产生不同汇总；只有均值精确相等的那一种事件处理被接受。

拟议事件键是：

`AQS 站点 + 日期 + 参数 88101 + POC + 方法代码 + 事件类型 + 上述原生采样时长`

共址设备如果连到同一键，是同一条参考，不按设备数重复计费。这个键只在联结表里使用。因为还有一行不能连上，它没有被交给面板筛选。
