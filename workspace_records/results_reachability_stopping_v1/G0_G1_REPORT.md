# 独立控制层的定义与工程核验

日期：2026-10-12。范围：方案 2 的单步前瞻停止实现和无标签门槛，不是旧 RAVEN 身份同步。

G0 独立控制范围放行：`stage2_r3.py` 中计算/网络时长先于且不依赖版本年龄生成；trace 的实际到达等于注册加两段服务时间。由此冻结同一物理完成事件用于共同控制比较。原 U、原 tau、旧 Gate、oracle 和预测标签均不作为新控制输入。新版版本落后量是另行冻结的共同原始随机数，不复用旧缓存的模型版本。

该改动构成新的受控时机协议，不能把新 fixed_time_1 的结果称为旧 Uniform 253.1132 的复现。缓冲接收、版本规则与实际组成用于全部对照，不单方面给予新控制更多可用数据。

G1 适用命题：停止动作对当前接收历史与冻结暖启动模型可测；最长窗口 4、网格 0.1，因而有有限截止；每客户端只保留一条未消费消息，消息只能消费一次。代码中的逐事件过滤、版本更新与消费断言核验了实现路径。

完整已知核的 Bellman 最优性只作为条件命题，不归属于当前单步经验策略。4 场景平均既无真实核误差界也无全局最优性保证；本轮通过配对门槛直接检验是否有发展价值。几何代理未获得 RMSE 转移保证。

停止后对既有产物进行独立审计，未重启控制实验：六个策略全部关闭记录重新检查时间、下载版本、年龄、客户端唯一性和权重可行性；全部共同网格指标重评分；未来 payload/版本落后量扰动不改变 t≤20 的冻结预测器。参见 COMPLETED_ARTEFACT_AUDIT.json、INFORMATION_AUDIT.json。
