# 方案 2：部署目标收益驱动的聚合停止，分层执行协议

日期：2026-10-12。本文件先于新方案的性能计算冻结。

## 研究对象与上一轮停止

上一轮 detector_v1 的 STOP_METHOD_IDENTITY_MISMATCH 表明旧论文与代码配置不同，未运行检测器，并非算法性能失败。本轮新建独立控制研究，不恢复旧 STOP，不将旧缓存称作新方法结果。

主方法：target_gain_stop。它是可解释的单步前瞻停止策略，属于方案 2 提出的近似实现；不称为全局最优停止算法。聚合时点成为控制变量，Design 的配置与诊断 Gate 不参与这个控制。先证明因果性与有限截止，先做无标签控制门槛；通过后才允许构建共同聚合器的端到端训练。

## 受控环境与信息约束

读取 raven.mcs 项目 Traffic 的自然事件轨迹，不截取 K=8 条件子集。原感知机会、O、设备成功及计算/网络时间不变；底层 stage2_r3 的服务时长不依赖模型版本，因此可在相同物理完成事件上比较新控制。

固定注册机会时钟，每个原窗口对应一个时间单位。服务完成时间是 registration_time+compute_duration+network_duration。物理成功指 compute_success 与 network_success 同时为真；原 U 包含旧截止时间和旧模型版本条件，禁止沿用。

下载版本在实际注册时由当前服务器版本及一份事先生成、所有控制共享的版本落后量确定。落后量沿用生成器的 80% Uniform{0..5}、20% Uniform{6..8} 模型，并对不存在的早期版本截断。它是新受控协议的原始随机变量，不声称重演旧缓存的 tau。每次关窗版本增加一次；可用性随新的实际版本变化重新计算。

成功完成的消息进入未消费缓冲区，可以跨原机会窗口保留。每客户端最多保留一条未消费更新，以免重复消息绕过客户端 cap。超过当前版本年龄 5 的消息剔除；每条消息最多消费一次。该缓冲接收语义用于全部对照，不能称作原固定窗口 runner 的逐字复现。

调度器只看已完成的消息和已冻结的历史预测器。源码中存在的未来到达、oracle_p/q、隐藏变量和标签不向决策函数暴露。读取 atomic 表时只取 unit_id、target_group、split、support_flag；目标 μ 来自冻结 TEST 支持元数据，不读取 TEST 目标值。消息组成是实际观测单元的经验群组比例；不是 RAVEN 校正后的组成或风险保证。

## 冻结方法

时间网格 Δ=0.1，最长聚合窗口 D=4，前 20 个时间单位使用共同 fixed_time_1 暖启动。只用暖启动时已完成的消息构建下一网格完成批次的经验分布，随后冻结预测器。不得用后半程轨迹拟合当前种子的预测器。

当前合法消息组成矩阵 Q 与完整 μ 上，使用现有 cap=max(0.5,1/K)、ESS_min=min(3,K) 的实际自适应约束。给定消息下载版本年龄 z_j，定义即时聚合损失

\[
g(S)=\min_a\left[\frac12\|Qa-\mu\|_1+0.02\sum_j a_jz_j/5\right].
\]

这是几何—陈旧性代理损失，不是 RMSE。若没有消息，g=1，不能用空集合获得更好分数。单消息/小于 3 消息时的退化按相同规则保留并记录，停止策略至少等到 3 个不同客户端才可主动关闭；截止时间到则执行共同后备规则。

每个时点使用冻结的历史批次模型生成 4 个下一网格场景，计算单步平均未来 g。增量等待成本为 0.20·Δ/D。若预期 g 的下降大于该成本，继续等待；否则关闭。超过 D 强制关闭。场景随机数由独立 RNG 与时点键生成，不消耗训练随机数，不因基线运行顺序变化。

全部权重、候选、版本与停止原因保存。0.02、0.20、4 个场景均是预注册值，不按结果调整。预测器是经验模型，未证明其覆盖真实未来分布；不声称策略在真实过程全局最优或不会变差。

## 必要证明

P1 因果性：当前缓冲由 registration≤t、completion≤t 的事件与过去关窗产生；预测器只由 t≤20 的已完成事件构造；未来模拟是历史模型的独立随机数。因此停止判断对合法信息历史可测。需要用未来日志扰动核验信息隔离。

P2 有限截止和唯一消费：最多 D/Δ=40 次网格判断后强制关闭；关窗原子性执行消费与版本递增；每客户端保留一条候选且每消息只消费一次。

P3 条件 Bellman 命题：在真实转移核 P 已知的有限截止模型中，V_D=g，V_h(S)=min{g(S), cΔ+E_P[V_{h+1}(S')]}；倒推归纳证明最优性。它是问题基准，不是当前经验单步策略的最优性证明。

P4 单步决策：在冻结经验转移核 Phat 下，比较 g 与 cΔ+E_Phat[g(S')] 给出“立即停止或再等一步”的模型内最优动作；4 场景估计存在误差，不能直接当真期望。记录这一近似，实际表现由门槛决定。

P5 代理与任务区别：即使 Q 更接近 μ，也没有自动 RMSE 改善；风险转移需要共同模型状态、组内条件稳定性、有效校正及梯度假设。多步本地训练和动态陈旧性不能直接套用几何证明。

P6 选择概率改变：新可用性含 arrival≤实际关闭时点、实际版本年龄、物理成功及观测存在。旧 q_use/旧 U 不适用。正式端到端若使用 Use/IPW，必须对完整新策略重算 propensity，并检查 positivity/裁剪偏差。几何门槛不使用 propensity，允许先独立执行。

## 分层门槛

G0：核验服务时间可重用、实际下载/关闭时间可实现、μ 与群组映射、旧停止不恢复。证明 P1/P2/P6 的工程语义。身份冲突不阻止本轮独立几何门槛；进入旧 RAVEN 的比较前必须解决。

G1：完成 P1–P6 的适用/条件标注。实现唯一关键路径核验：当前输入不暴露未来；关闭次数、消费与版本一致；原 U 不被读取；正常约束与小 K 退化可行。求解异常不接受并停止，最多一次明确数值错误修复，不调整方法。

G2：Traffic/41001 的同物理事件配对控制实验。基线：fixed_time_1、fixed_time_2、fixed_time_4、fixed_K8_timeout4，以及不使用 μ 的 age_count_trigger。所有基线使用同一缓冲、同一目标投影聚合器、版本年龄与消费规则。K=8 只是触发对照，不声称完整复现 FedBuff。

从 t=20 至 t=100，在共同网格上记录“最近一次已释放聚合结果”的损失并积分。主指标

\[
J=\text{time-average}\{\tfrac12\|Q_{release}a-\mu\|_1+0.02\,age_{release}/5+0.20\,window\_duration_{release}/4\}.
\]

评价单位是完整轨迹。另记录几何距离、等待时长、实际消费消息、全量注册/物理完成消息、过期数、版本数和 CPU 时间。各控制使用相同机会时间、发送尝试、服务完成与截止总时域；应用到模型的消息不同是策略作用，不能说它们训练样本完全相同。

G2 停止：新 J 高于最强共同信息基线（浮点计分容差 1e−7）立即 STOP；决策与某个固定时长策略完全相同则 STOP_NO_DISTINCT_MECHANISM；改善不足 2% 则 STOP_NO_INCREMENTAL_VALUE；预算超限或信息/数值错误则 STOP。新方法 J 值降低只是代理价值，不能报告 RMSE 收益。

G2 PASS 后才按 41002→41003 继续，同样每条完整比较后停止；三种子通过后才做 SensorScope 几何回放及 U-Air 失败条件回放。任一阶段不得删除失败条件。总 CPU 上限 60 分钟、单进程最多 2 线程，门槛前 GPU 训练 0。

G3：仅 G2 所有条件通过后，独立实现 configured-Design 的共同骨干/聚合器并检验 P6；保留 legacy 路径，不复用原 gate-controlled 缓存当新方法结果。新模型冻结 Common-NDMF 与现有 Adam 0.003、rho=0.5，不搜新骨干。预先建立同物理机会、相同 local sample/optimizer/通信预算的固定时长/固定 K 与控制完整实现。按既有 200 遍历预算和开发验证规范执行；新方法在首个完整配对开发运行低于最强适用简单基线或同协议最强联邦基线时，立即停止，不自动延长至 400 或追加配置。

G3 PASS 后才冻结正式配置，确认42001–42020；每次完整配对后严格判断，提前停止时不伪造全20种子统计。消融删除目标距离、删除等待成本、删除陈旧性；近邻完整外部方法需适用时补齐，不用触发组件替代完整性能基线。正式训练阶段若关键预算或共同基线无法实现，停止而非以几何结果填主实验。
