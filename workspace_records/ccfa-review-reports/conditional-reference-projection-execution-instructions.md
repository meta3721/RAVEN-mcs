## 一、这条路究竟做什么

这里的“第一条路”指此前提出的“明确使用条件的简化校准”，不是热点筛选、跨窗口停止，也不是普通缓存的继续版本。

方法主体保留：预配置的 Design、原有 Obs/Use 校正、局部 Hájek 训练、校正参考质量，以及完整的单纯形/cap/ESS 可行约束。服务器把完整 P2 换成“离校正参考最近的可行权重”。不再为目标失配、债务、方差和陈旧代理分别设置 P2 优化项。

使用条件先在部署前、根据历史验证资料确定；整段部署使用一个固定配置。不先发明逐窗口预测器，不让 coverage Gate 改写 Design。覆盖、参考集中度和投影改变量用于解释适用性，不被包装成预测风险保证。

本路线分别回答两个问题：

1. **简化是否值得？** 相对完整 P2，参考投影能否降低实际成本，同时保持关键端点？
2. **校准是否值得？** 相对强简单基线，参考投影是否带来预测收益，或在一个事先声明的目标质量分配需求下，提供值得采用的结构收益？

问题 1 通过，不能自动视为问题 2 通过。若最终只能说明 P2 可被更简单的方法替代，应调整论文贡献归属，而不能声称已经建立新的预测优势。

## 三、冻结方法身份

### 3.1 简化方法 P：Reference projection

沿用当前确认版本中的校正和训练定义：

\[
m_{k,r}=\sum_i R_{k,r,i}O_{k,r,i}a_{k,r,i},\qquad
\widehat\beta_{k,r}=\frac{m_{k,r}d_{k,r}}{\sum_{j\in\mathcal A_r}m_{j,r}d_{j,r}}.
\]

其中 \(a\) 为原 Design/Obs 稳定化权重，\(d\) 为原 Use 稳定化校正；所有截断、历史估计和信息时点沿用冻结来源，不能另换成均匀本地损失。

对 \(K_r=|\mathcal A_r|>0\)：

\[
\mathcal C_r=\{\alpha:\mathbf1^T\alpha=1,\ 0\leq\alpha_k\leq\bar\alpha_r,
\ \|\alpha\|_2^2\leq1/\bar E_r\},
\]

\[
\bar\alpha_r=\min(1,\max(0.5,1/K_r)),\quad
\bar E_r=\min(3,K_r),\quad
\alpha^P_r=\arg\min_{\alpha\in\mathcal C_r}\tfrac12\|\alpha-\widehat\beta_r\|_2^2.
\]

客户端仍做原本的两步局部 Hájek 训练；服务器使用原归一化 displacement 与学习率更新。空活跃集继续沿用原 carry-forward 规则。若来源核对表明 cap/ESS 并非上述值，先报告冲突，不能静默换值。

从 P 中移除完整 P2 的 group、debt、variance、staleness 优化项及仅为这些项服务的计算。原有异步时效资格、过期淘汰和客户端版本语义保留；移除 staleness 惩罚不等于取消消息有效期。

计时中应反映真实简化：不能先运行完整 P2 再丢弃结果。需要的结构诊断可作为单列审计成本，不伪装成免费，也不强迫 P 在部署中维护已经不用的债务状态。

### 3.2 核心对照

- **F：完整 RAVEN-Design/P2。** 原有完整目标、状态和参数，不重新调参。
- **U：matched-support Uniform。** 与 P、F 共用 Design-on、局部校正、参考构造和有效支持协议，仅服务器权重设为 1/K。P−U 回答参考权重相对均匀分配的增量。
- **TwoStage-Hájek、FedAvg。** 使用各自完整、已确认的原协议；作为部署竞争者，不强行改成与 P 同支持后仍沿用原名称。
- **廉价预测基线。** 复用适用的 Delivered-SpatialMean、Delivered-CellBlockMean 等既有完整实现与有效预测缓存。其训练资料、可用标签和部署特征必须合法且与任务一致。
- **其他已有强对照。** 核查原 City Scanner 的 FedAU、ObsUse 等合法 validation 缓存；适用且完整的结果必须加入比较，不能因本轮只新跑五臂就从竞争者中删除。若已有证据显示某个遗漏方法比默认外部对照更强，而缓存不可用，在 S0 冻结前以它替换一个外部训练名额，并说明理由；仍保持三种子、五臂上限。若强对照无法合法复用或纳入，报告比较范围受限，不能发布覆盖该对照的 GO 结论。

从开发 validation 上全局选出最强适用的非 P、非 F 基线 \(B^*\)，以三种子平均最终 RMSE 为准，不逐种子更换。其余对照仍全部报告，不能只与最弱或恰好被打败的基线比较。

U、P、F 是服务器规则机制比较；外部基线是端到端实用价值比较，二者不能混为同一消融。

P 与 F 是各自独立训练的轨迹。它们的模型、更新、合法历史状态可以随训练分叉。必须共享相同的初始条件和外生事件，不要求人为锁死本应由各自历史决定的状态，更不能用 F 的更新重放 P 权重来冒充 P 的训练结果。

### 3.3 不新增在线 Gate

本轮所有 P、U、F 运行保持 Design=on 的整段预配置；coverage Gate 只诊断。新方法的部署选择发生在运行开始前，选择的是“这一段使用哪个完整训练配置”，不是在当前窗口结果揭晓后改变 Design。

## 四、可以先写清楚的理论部分

S0 中给出以下短证明及其适用范围，不要求再造一套复杂收敛理论来启动筛选。

1. **存在、唯一与约束。** 非空窗口的 Uniform 属于 \(\mathcal C_r\)，该集合为非空紧凸集；严格凸的平方距离目标有唯一最优解，因此权重归一化、cap 和 ESS 约束成立。
2. **参考投影的几何性质。** 对任意 \(a\in\mathcal C_r\)，由投影最优性 \((\widehat\beta-\alpha^P)^T(a-\alpha^P)\leq0\)，推出
   \[
   \|\alpha^P-a\|_2^2\leq\|\widehat\beta-a\|_2^2-\|\widehat\beta-\alpha^P\|_2^2.
   \]
   这是相对“可行参考”的欧氏几何性质，不保证目标组失配、预测 RMSE 或真实风险下降。
3. **支持的不可修复部分。** 若 \(M_r\) 每列是归一化组构成，令 \(Z_r=\{g:M_{gk,r}=0\ \forall k\}\)，则任意可行权重都有
   \[
   \tfrac12\|M_r\alpha-\mu\|_1\geq\sum_{g\in Z_r}\mu_g.
   \]
   证明使用两侧总质量均为 1 和未覆盖组的质量差。投影不会创造这些组的实际支持。该式是逐窗下界，不能直接冒充跨窗聚合端点的相同下界。

如需陈述目标恢复，必须沿用原有正性、选择机制可识别性与稳定化误差条件；不能因为权重可行或 ESS 达标，就称参考为无偏或预测为安全。

\(K\leq3\) 时，本方案的 ESS 约束使 \(\mathcal C_r\) 退化为 Uniform。这个事实可用于解释投影没有可操作空间的窗口；不得为了获得非退化窗口临时放松 ESS。

6. S2—S3 累计预算：1200 CPU 秒、1800 秒 wall，包含新运行、验证评分、失败尝试和执行检查；历史已花费成本另列，不冒充本轮支出。每条开始前检查剩余额度，耗尽即停止。
7. 有完整恢复实现则保存实际恢复状态；没有时保存中间证据并标 PARTIAL，不宣称部分模型可精确接续。无需先建一个新的复杂恢复系统才能进行这次短试验。

### 记录内容

每个运行输出：完整配置、种子、实际窗口数、终点模型、validation 预测或逐组 MSE、目标 RMSE、WorstGroupRMSE、两类累积结构距离、实际有效服务器步数。

结构日志至少保留逐窗活跃支持、beta、alpha、组构成、cap/ESS 残差和时间戳。若 client–stratum 结构字段不可得，该端点标缺失，不能由 group 指标推算。

成本分开记录：数据/初始化准备、实际部署训练与聚合、额外诊断、validation 评分；各有 CPU/wall，整个 worker 另有总账、峰值 RSS、最小可用内存。不得再次用总 wall 代替部署 wall，也不得用 CPU 比例补 wall。

仅终点是必要预测评分。若已有轻量检查点可兼容保存，最多另存 20/60/80 窗用于解释；曲线不得替代第 100 窗终点，也不据此选择早停时间。

### 出口

通过：冻结清单中的完整独立轨迹与评分齐全，进入 S3。

资源失败：`PAUSED_RESOURCE`。不能据此判定科学方法失败，也不能用部分轨迹做主对照。

执行失败：`FAIL_EXECUTION_OR_SCORING`。列明受影响的具体臂与种子，保留已完成运行，不把其他已完成结果一起清空。

## 八、S3：固定比较与采用判断

### 指标定义

对方法 A、种子 s：

- \(R_{A,s}\)：第 100 窗后 validation 的目标 RMSE；由逐组 MSE 按固定目标加权后开平方。
- \(W_{A,s}\)：同一终点的 WorstGroupRMSE，不能用过程平均替代。
- \(G_{A,s}\)、\(H_{A,s}\)：原口径的累积 group/client–stratum L1 距离。
- \(C_{A,s},T_{A,s}\)：同口径的部署 CPU 与部署 wall。

种子等权；主相对变化使用均值之比，例如 \(100(\bar R_P/\bar R_B-1)\)。结构收益换算为目标质量百分点：\(50(\bar G_B-\bar G_P)\)。这里 0.5 pp 对应 L1 距离差 0.01，不能误写成 0.5% 相对改善。

不得对缺失组丢掉目标质量再归一化；如评分覆盖不足，报告覆盖缺口并停止受影响的主比较。

### 两类预登记结果，分别判定

下列阈值是本次低成本筛选的拟定实践门槛，不是 CCF-A 投稿规定，也不是由三种子证明的统计非劣界。执行前冻结，结果出来后不放宽。

**A. 预测价值成立的开发信号：`GO_PREDICTIVE_SCREEN`**

同时满足：

- 相对开发 validation 选出的 B*，平均终点 RMSE 改善至少 2%；至少 2/3 种子方向有利。
- 相对 B*，平均终点 WorstGroupRMSE 恶化不超过 1%。
- P 相对其余任何适用强基线的平均终点 RMSE 均不恶化超过 1%；完整报告这些对手，不能只报 B*。
- 相对最强适用联邦基线，P 的平均部署 CPU 和 wall 均不增加超过 20%；廉价非训练基线另列实际成本，不混入联邦计时比。

这是值得做独立确认的信号，不是已经证明最终胜出。

**B. 条件替代价值的开发信号：`GO_CONDITIONAL_REPLACEMENT_SCREEN`**

同时满足：

- S0 已有明确且事先登记的目标质量分配需求；若没有，只能记为简化证据。
- 相对 F，P 的平均终点 RMSE、WorstGroupRMSE 恶化各不超过 1%，两类累积结构距离各不恶化超过 0.5 pp。
- 相对 U，P 的平均 group 结构错配减少至少 0.5 pp，至少 2/3 种子方向有利。
- 相对 B*，P 的平均终点 RMSE、WorstGroupRMSE 恶化各不超过 1%；“结构更好”不能覆盖超线的预测损失。
- 相对 F，P 的部署 CPU 与 wall 均减少至少 20%；两类成本必须真实测得。

此分支只支持“在明确目标分配要求下，投影是比完整 P2 更经济的候选”，不支持比所有简单基线更快或预测更好。若操作者主要需要 client–stratum 端点，必须在 S0 登记并采用同样的 0.5 pp 增量门槛，不能看到 group 更有利后才改主端点。

### 其他结果的处理

- 仅 P 比 F 更便宜、质量相近，但没有 A 或具名需求下的 B：`SIMPLIFICATION_ONLY`。可以支持降低方法复杂度和收窄论文主张；不能宣称补齐主要应用价值。
- P 在质量与结构上均被强简单基线支配：`NO_GO_PRACTICAL_VALUE`。停止这一轮新增实验，不再筛选更容易获胜的目标、时期或子集。
- 有端点超过已冻结保护线：`FAIL_PREDICTION_OR_STRUCTURAL_GUARD`，报告具体差距。不能选择另一种平均方法掩盖终点代价。
- 只有 timing 缺失：`COST_UNRESOLVED`，不是已测成本超线。若预测已失败，不能为时间补测申请继续训练。
- 三种子方向冲突或效应小于门槛：`INCONCLUSIVE_SCREEN`。报告可见效应和剩余不确定性；不自动加种子、寻找显著性。

每个对照给三个配对差和均值即可。本轮不做针对三个已用种子的伪精确显著性检验，不将逐窗口当独立重复。两类 GO 都只是进入下一阶段的候选，不能修改历史失败为成功。

同时报告每个种子是否越过预测保护线。均值通过但某个种子存在明显代价时，保留该风险并限制采用结论；不能用有利种子的平均抵消后声称所有运行都受到保护。

## 九、怎样把结果变成真正可执行的“使用条件”

先采用最简单、可审计的部署前规则：

```text
输入：预先确定的目标和数据协议；部署前实际可得的历史验证资料；
      由这些历史资料选出的强简单基线 B*；冻结的端点与容忍线。

如果参考构造所需信息在时间上不可得，或历史评估不符合部署协议：
    本规则不适用；不声称可在线识别，保留已有合法基线。
否则，如果历史资料满足预先登记的预测采用条件 A：
    下一完整运行采用 Reference projection。
否则，如果已有明确目标分配需求，且历史资料满足条件替代条件 B：
    下一完整运行采用 Reference projection。
否则：
    下一完整运行采用 B*。

运行开始后固定该选择，不依据本次 test/未来标签或当前更新结果切换。
```

这首先是配置选择规则，不称作新的自适应联邦算法。B* 的配置也必须在开始前固定；若它不是神经学习器，就运行其完整原算法，不强行套用 P 的状态。

如果所有情形都回退 B*，只能说明规则采取了回退，不能宣称校准有价值。如果所有情形都使用 P，则没有必要强调复杂的选择规则，报告固定 P 的适用范围即可。

规则的真实价值须在后续时间块/新采集块评估；将已完成模型逐窗口拼接成“规则预测”，或逐 seed 选择赢家，均不能替代该评估。对于部署前整段二选一，只有源模型本身属于同一合法、完整的未来评估协议时才可复用其整段结果。

选择成本也要记账。若一次历史比较成本为 T_select，而每次部署相对 F 节省 T_F−T_P>0，则成本回收需要部署次数满足 N(T_F−T_P)>T_select；以实际数值报告。不能只报投影求解快，却隐去每次选方法都运行多条轨迹的开销。

低支持、ESS、clipping 等仅用于解释已经观察到的适用范围。若要训练“用这些特征预测哪种方法更好”的元模型，本轮禁止自动开展；那会增加选择偏差与新的验证需求。

## 十、S4：只有筛选有价值时才提出独立确认申请

S4 不自动执行。A 或 B 通过后提交具体申请；SIMPLIFICATION_ONLY 原则上先做论文主张与方法定位评估，不以冲投稿为由继续堆实验。

独立确认申请必须说明：

1. **新信息来自哪里。** 优先新的未使用时间块或新数据采集；只增加随机种子属于同一数据上的优化稳定性复核，不是独立数据验证。若不存在未看过的数据，明确上限，不把旧 test 重新封存后改称盲测。
2. **一主一辅。** 只选择 A 或有实际部署需求的 B 作为确认主目标；不能确认失败后改宣称另一个为原主要目标。
3. **最小充分比较。** P、B*、F、必要的 U；既有强外部方法及适用简单预测基线仍保留。若换平台或硬件，重新匹配计时条件。
4. **冻结后评估。** 所有方法只使用训练与历史校准资料；最终评估数据只在规则、参数和比较对象锁定后读取。
5. **区间与重复单位。** 随机种子衡量训练随机性；时间/空间块衡量相应数据泛化。按真实依赖结构做配对区间，不将窗口或重叠记录当独立样本。确认预测优势需区间支持正收益；宣称 1% 非劣需预先规定的一侧上界落在容忍线内。
6. **样本与成本。** 用开发结果的配对波动估算达到实践线所需重复数，给出具体有限预算和可在本机完成的串行清单。没有预算可行性就提交受限结论，不自动申请大规模。
7. **选择规则的增量。** 若要声称条件规则有价值，未来至少须存在可识别的不同部署块，并与始终 P、始终 B* 比较；只在一个块采用 P，证明的是固定 P 的效果，不是选择规则的泛化优势。

无需在开发筛选失败后立即跑 SensorScope/U-Air、visit、强缺失率等扩展网格；现有数据已能提供边界线索，不要通过无界试验寻找一次胜利。

1. 首个失败阶段、具体条件与已冻结阈值；

4. 已完成资产、不可使用的部分、已消耗与剩余预算；
5. 已取消的后续任务；
6. 解释已知事实与尚未证明的原因，不把相关性写成归因；
7. 最多两项后续选项及其代价，等待用户决定。不得自行放宽门槛或换方法续跑。

## 十二、论文能怎样使用最终结果

若 A 获独立确认：可以考虑将参考校正+投影作为预测有效的完整简化方案，原完整 P2 作为增强变体或比较项。首先同步算法、理论适用范围、贡献与实验身份，不只修改名称。

若 B 获独立确认：主张限于具名目标分配需求下的结构收益和成本取舍，保留预测保护条件及适用范围，不写普遍预测优势。

若仅 SIMPLIFICATION_ONLY：最有价值的修改可能是承认投影已取得主要可用效果，删去对完整 P2 必要性的过强表述。该结果能改善论文可信度，但未必足以支撑 TMC 方法论文的核心创新与实用价值。

若失败：保留有限证据、停止本轮，不再将旧模型换指标评分当作新方法收益。

本指令不授权自动改论文。后续若进入写作，交由 `ccf-paper-writer`，并用 `ccf-integrity-auditor` 核对主张与结果；所有未知结果保持 TBD。

### 公开方法背景，仅用于界定新颖性

- Wang 与 Zubizarreta 的 [Minimal Dispersion Approximately Balancing Weights](https://arxiv.org/abs/1705.00998) 已研究平衡与权重离散程度的取舍。因此“增加权重约束/降低权重波动”本身不足以建立新颖性。
- Li、Lam 与 Prusty 的 [Robust Importance Weighting for Covariate Shift](https://proceedings.mlr.press/v108/li20b.html) 讨论了分布差异大、权重估计不良时的重要性加权方差问题。因此 ESS、clipping 或参考稳定性不能代替真实预测验证。

这些公开背景并未证明或否定本项目的完整新颖性；本轮也不对私有稿件内容进行外部检索。
