# 两条补强路径的结果审查

审查日期：2026-10-19。范围：第一条“明确使用条件的简化校准”，第二条“改变支持获取／消费机制”中已经实际执行的支持保留与消费分支。本次仅整理已有结果，没有新增训练、重评分或论文修改。

## 1. 总体结论

两条路径都完成了有信息量的筛选，但均未建立原定的整体采用价值。当前应停止这两个现行协议的新增训练，保存机制与取舍证据，重新明确论文中各组件的贡献。

第一条的最终状态为 `NO_GO_PREDICTIVE_SCREEN`；条件采用分支 B 没有真实部署需求，保持未注册。第二条中，原支持感知调度 S 在无训练回放阶段为 `NO_STRUCTURAL_ADVANTAGE`；后续普通固定缓存 F2 虽通过过程平均收益门槛，却为 `FAIL_PREDICTION_GUARD`，部署 wall 证据另有缺失。

停止决定不是“所有相关思想永远无效”的理论结论。它适用于已冻结的 City Scanner measured-O 协议及三个开发种子。主动招募、新观测获取、改变候选支持集合等机制本次没有执行，不能随消费分支一起判为失败。

两条路线的正式训练各包含三种子、五臂、每臂 100 个逻辑窗口，合计 30 条既定训练轨迹。它们复用了相同的开发种子，不是 30 个独立数据样本，也不是两次独立数据确认。前面的无训练回放、探针、实现检查不计作新的预测实验。

## 2. 第一条：明确使用条件的简化校准

### 初始问题与实际方案

初始问题是：完整 P2 中的复杂项是否必要；能否保留参考校正与可行投影，用更低成本提供足以被采用的效果。

实际 P 保留 Design/Obs/Use 校正、局部 Hájek 训练、校正参考 beta 与 cap/ESS 可行约束，把服务器决策改为 beta 的欧氏投影。与完整 F、同支持 Uniform U、TwoStage-Hájek、FedAvg 比较，并纳入两项合法廉价预测基线。Design 全程预配置 on，coverage Gate 只诊断。

当前没有确认的操作者或区域质量分配合同，因此本次没有验证一个真正的条件部署选择规则。实际检验的是固定参考投影的预测效果，以及相对完整 P2 的简化取舍。

### 已完成证据

三种子 33001、33002、33003，各五臂，均完成 100 窗。只对 validation 评分；四组覆盖完整。统计为种子等权均值及均值之比，不构成显著性或非劣性证明。

主要数值如下，均来自 THREE_SEED_COMPARISON.csv：

- **对最强适用基线 TwoStage：**P 平均目标 RMSE 为 0.6707913142，TwoStage 为 0.6702248195；P 高 0.084523%，有利种子为 0/3。平均 WorstGroup 高 0.096860%；group/client–stratum 错配也分别略高 0.061572/0.016409 pp。P 的 CPU/wall 点估计约低 2.263%/3.597%，不足以据此宣称优越的成本质量取舍。
- **对同支持 Uniform：**P 的 RMSE 降低 1.532271%，三个种子方向一致；group 错配降低 6.096276 pp，client–stratum 错配降低 12.865359 pp。这识别了参考权重相对均匀服务器权重的机制增量。
- **对完整 F：**P 的 RMSE 降低 0.321414%，三个种子方向一致；平均 WorstGroup 降低 0.420288%；client–stratum 错配降低 1.024841 pp。但 group 错配增加 0.689175 pp，CPU 仅降低 2.215444%，wall 仅降低 2.083915%。
- **对 FedAvg：**P 的 RMSE 降低 1.295948%，三个种子方向一致。对两个廉价均值基线也有预测优势，但这不能替代与 TwoStage 的直接比较。

### 判定

预测筛要求相对全局 B* 至少改善 2%，至少 2/3 种子方向有利。实际 B* 为 TwoStage，P 没有一个种子胜出。失败不是只差一个略高的效果门槛；放宽到“点估计略有改善”，也不能使当前结果通过。

简化侧也未达到整体标准：相对 F 的 group 代价 0.689175 pp 超过 0.5 pp 容忍线，CPU/wall 节省约 2%，而非要求的至少 20%。两项标准分别失败，不能仅去掉结构门槛后宣布整体替代成功。

分支 B 的状态是 `NOT_REGISTERED_NO_DEPLOYMENT_CONTRACT`。这是没有开展相应部署检验，不能记为通过，也不能伪装成统计上的失败。

最终保留 `PARTIAL_TRADEOFF_EVIDENCE`：参考投影与完整 P2 各有端点优势，缺少一个已确认的实际选择理由。不能把 P 优于 U 写成 P 已超过强简单基线。

### 尚存边界

FedAU/ObsUse 没有本协议的合法 validation 逐单元资产，结果不覆盖这两项。三个种子不是新的独立数据确认。新运行共同采用了服务器参数存储克隆修正，绝对分数不能直接拼入旧论文结果后归因于投影。

历史失败尝试部分 CPU 未计量；新增后两种子实测 370.4375 CPU 秒、383.5549 秒 wall，在该批 600/900 上限内。训练本身已经完成，继续加预算不能消除当前效用缺口。

## 3. 第二条：支持保留与消费机制

第二条实际形成了三个不同层级，必须分别判定：原支持感知 S 调度、账本问题及零质量隔离修订、普通固定缓存的真实学习验证。后一个分支的结果不能改写前一个分支的身份或通过状态。

### 3.1 原支持感知 S：在结构筛选阶段停止

原问题是：在相同上传机会、关闭网格、终点、最大驻留与容量限制下，按目标支持互补性保留并联合消费更新，是否值得进一步训练。

原臂包括立即 I、普通年龄缓存 F1/F2、支持感知 S。S 在满足互补距离减少条件时提前释放，否则在年龄 2 达到期限时释放。主块 measured-O 为 33001–33003；visit 只作边界。

无训练回放表明：

- S 确实发生了 HOLD 与互补释放，不是立即聚合或固定缓存的简单改名。
- 主块互补释放合并为 27/300=9%，低于预设 10%。
- 更关键的是 seed 33002：普通 F1 在时间平均 D、已提交正质量平均驻留、p95 驻留上同时严格优于 S。该支配只出现在这个种子，不能写成全部种子均被支配。
- S 三项对应值约为 0.039244、0.711、2；F1 为 0.038427、0.410、1。

最终 `NO_STRUCTURAL_ADVANTAGE`。实现核验后来通过，仍不能把科学筛选改成通过。该 S 候选没有进入真实神经训练，不能说它已经在预测上失败，更不能用后面的 F2 过程收益声称 S 成功。

### 3.2 账本审计和零质量隔离：找到并修正了真实消费问题

后续审计确认：零参考质量消息会覆盖同客户端的正质量消息，也会占用有效缓存槽位。主块旧规则中，零替正次数为 F1 49、F2 76、S 73；同客户端替换还会使一部分独特观测 ID 从未进入任何 committed 消息。

修订只将 m=0 的消息隔离出有效 pending：不覆盖正消息、不占有效容量。参考零质量不等同于原始观测本身完全没有预测信息，因此不能写成“删除所有无价值观测”。

无训练新旧规则对照显示：

- `zero_replaces_positive` 变为 0，池中零质量消息数为 0。
- 三种子普通 F1 的正质量提交总数从 3019 增至 3070，增加 51。
- F2 从 2525 增至 2622，增加 97。
- 两类缓存三种子中，正质量提交均增加；保留的观测 ID 也有改善。

这些是有用的工程和调度证据。它们证明了特定覆盖/占位问题被修正，但没有单独的旧规则神经训练对照，不能据此确定零质量隔离带来多少预测收益。

普通缓存的可达几何距离改善也真实存在。但 D 是同支持下的最小可行 TV 距离，既不是实际参考投影误差，也不是预测 RMSE，不能直接作为下游任务收益。

### 3.3 零质量隔离普通缓存：过程收益未通过终点保护

这次真实训练比较 I-Proj-ZS、F1-Proj-ZS、F2-Proj-ZS、TwoStage、FedAvg，共 15 条、每条 100 close，评分为预先规定的九个 validation 检查点，共 135 点。

全局缓存候选 F*=F2，全局非缓存对手 N*=I，选择均依据三种子平均九点 RMSE 指标 L，没有逐种子换赢家。

三种子汇总：

- **九点平均目标 RMSE：**I 为 1.9086720736，F2 为 1.8533013771；F2 改善 2.901006%，2/3 种子方向有利，达到过程主收益门槛。
- **最终目标 RMSE：**I 为 1.5947612757，F2 为 1.7556338482；F2 恶化 10.087565%，三个种子终点均更高，明显超过允许恶化 1% 的保护线。
- **九点平均 WorstGroup：**改善 2.731409%。这不是最终所有困难组均改善。
- **部署 CPU：**总和比 0.7971538，减少 20.284617%。seed 33001 的部署 wall 未测，不能宣布完整三种子 wall 收益。
- **更轻的 F1：**九点平均 RMSE 仅改善 1.098641%，最终 RMSE 恶化 8.224714%，不能替代 F2 成为通过方案。

同时，I 每种子 100 次服务器更新，F1 为 50 次，F2 为 33 次；F2 正质量提交为 2622，而 I 为 3569，F2 另有 929 条正质量替换和 18 条终点未消费。步数、延迟和数据消费同时变化，这些是整体缓存策略的取舍，尚未分离每项的因果贡献。

最终状态为 `FAIL_PREDICTION_GUARD`；成本证据另列 `COST_EVIDENCE_INCOMPLETE`。即使补齐 wall，也不会改变终点质量失败，因此不值得为计时重跑。

### 第二条的范围结论

原 S 未证明相对普通缓存有额外结构价值；普通缓存获得过程与 CPU 收益，但没有保持终点质量；零质量隔离修正了可观察的消费损失，却没有单独预测归因证据。

这三条都是各自层级的有效结论。它们不能合并为“支持感知 RAVEN 已有预测收益”。实际没有训练完整 P2 在新缓存机制中的增量，也没有验证主动获取新的客户端/观测，因此这两项仍未回答。

## 4. 两条路径共同回答了什么

**原先的共同目标：**补齐主方法相对强简单方法的实用价值。

**当前共同结果：**几何与组件改善存在，但没有足以支持整体采用的任务与成本组合。第一条的主要瓶颈是对强基线没有预测增量；第二条的主要瓶颈是过程收益伴随显著终点代价。

失败不主要来自门槛过严：第一条 0/3 种子胜过 TwoStage；第二条终点恶化约 10%，而非只在 1% 保护线上小幅越界。现有结果也不表明换更强硬件会自动解决科学问题：两套既定训练均已完成，第二条训练总账约 457.53 CPU 秒、487.97 秒 wall，低于原限额。

两条路线不能按绝对 RMSE 排名。它们有不同的参考构造、本地损失、事件消费和版本推进协议，第一条还显式使用共同服务器参数存储修正。0.67 与 1.59 的差不是“第一条比第二条准确多少”的可比结果。

## 5. 对我此前建议的复盘

1. **应更早把强基线设为主要参照。** Uniform 是机制对照；P 胜过 U 不能闭合部署价值。TwoStage 在当前结果中已经拿到了相近或更好的预测效果。
2. **旧数据集的成本改善没有迁移过来。** 第一条的动机部分来自 SensorScope/U-Air 上投影相对 P2 的 26.57%/42.48% 历史 wall 减少；本轮 City Scanner 三种子只有约 2.08%。此前只能把前者作为探索线索，不能据此预期相似收益。
3. **第二条确实发生过方法转向。** S 未通过后，继续检验的是普通缓存与零质量隔离。它有诊断价值，但不自动保留“支持感知新算法”的创新主张。
4. **结构代理的筛选作用需要严格限定。** D 改善支持开展一次有限训练，但不能提高对预测收益的证据等级。真实训练后应以原任务条件判定，而不是回退用 D 宣布成功。
5. **补齐三种子的投入已完成使命。** 它使首种子的方向变得更清楚，没有产生 GO。继续追加种子不应成为默认下一步。

当初开展低成本筛选具有诊断价值；现在已没有依据把这两份现行协议继续升级为大规模主实验。

## 6. 哪些证据值得保留给论文

优先级较高的候选材料：

- 第一条的同支持 U/P/F 对照：能说明参考校正、投影与完整 P2 各自带来什么，并同时保留 TwoStage 的强基线结果。
- 第二条的“结构可达性改善与预测收益分离”结果：用完整九点曲线展示过程改善与终点代价并存，不能只展示早期优势点。
- 零质量覆盖与有效支持损失的事件账本、新旧规则的正质量提交对照：适合系统实现或机制诊断部分，表述为消费行为改善。
- 明确区分 S、普通 F1/F2、参考投影 P、完整 F 的方法身份，避免读者将不同结果归到一个名称下。

不应作为主张的内容：

- 参考投影或完整 P2 已超过全部强基线；
- 普通缓存全面改善预测精度且保持终点质量；
- 零质量隔离已经证明独立的预测贡献；
- 三种子缓存 wall 已降低或已通过独立确认；
- 这两条路径证明主动招募或所有支持获取机制都无效。

本报告不自动决定某个表一定进入正文。若论文仍以完整 P2 的部署收益为核心，两条路线目前只能提供机制与边界证据，不能代替缺少的核心正向证据。

准备纳入论文前，需对齐新旧实现版本，尤其是服务器参数存储修正与现有主表的关系。先检查原运行是否已采用等价处理；不能直接断言旧结果全部错误，也不能忽略已发现的执行差异。该核对不自动授权全量重训。

## 7. 当前处理建议

停止两个现行协议的新增训练、追加种子与事后目标搜索；保留模型、预测、账本和全部失败项。只做非训练证据归档及论文主张审计。

若仍要寻找方法级实用价值，下一次研究应有新的可证伪假设，例如实质改变可用支持集合，或真实存在的过程服务质量需求；先证明其数据与决策条件可获得，再设计新协议。不能把现在未注册的用途补写出来后，让旧结果变成通过。

继续研究新的方向与停止当前两个方案不矛盾，但新方向的成立与创新性都需要新的依据，本报告不授权立即启动。
