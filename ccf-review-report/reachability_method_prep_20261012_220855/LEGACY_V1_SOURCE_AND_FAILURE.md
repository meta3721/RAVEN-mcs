## 计算与生命周期

固定 Δ=0.1、D=4、T=100；t≤20 所有策略 fixed_time_1 暖启动。注册与完成按物理时间处理，同刻注册先于完成，网格到达处理先于该网格关窗。每次注册下载 `max(0, current_version−lag)`；共享的新 lag 为 80% Uniform{0..5} 与 20% Uniform{6..8}。它不是原 trace 的 tau。

完成消息有观测且 compute/network 均成功才进入池；版本年龄>5剔除。每客户端保留注册时间较新的一个消息；关窗消费整个合法池、清空池、版本+1；在途消息保留，其将来的年龄依赖本策略版本。旧源码空池关窗也版本+1；这是控制模拟器规则，不能默认等于真实模型更新。新方案须显式区分关闭次数和模型版本。

μ 来自冻结 TEST 支持单元的 target_group 计数，不读目标值。每条消息 Q 列为 observed_unit_ids 的**原始经验群组比例**。没有 Design、observation IPW、usable IPW、参考质量校正或完整 RAVEN debt/P2。

对当前 K 个不同客户端，约束是 a≥0、sum(a)=1、a≤max(0.5,1/K)、sum(a²)≤1/min(3,K)。K≤3 时 uniform 是这些约束的唯一可行权重，代码直接使用；K>3 用 CLARABEL 求解：

`g(S)=min_a { 0.5||Qa−μ||₁ + 0.02 Σ a_j(version−download_j)/5 }`。

缺失群组在优化目标中略去固定 L1 常数，最终 distance 在全 μ 上计分，因此不是有意删除目标支持。空池 g=distance=1。源码保留可行性检查和归一化后复查。

暖启动预测器按 10 个注册钟相位保存历史 **0.1 时间步完成批次**，只取 arrival≤20。历史批次中的年龄按共同暖启动版本计算，使用 observed_age 而非不可见未截断 lag。

非暖启动、非截止且 K≥3 时，从下一相位的历史批次抽 4 个场景，把该批次客户端覆盖加入当前池，保持当前版本，计算 next-step g。若 `g_current−mean(g_next)≤0.20×0.1/4=0.005` 就关窗，否则等待。无合法 K 时等截止。场景随机数由 seed/tick 键确定；这是一步经验前瞻，不是多步 Bellman 实现。

## 实际信息边界

| 部件 | 使用信息 | 限制与本轮核验范围 |
|---|---|---|
| load | unit_id/group/split/support；注册、物理服务与成功标记；observed IDs | 不读旧 U/tau/oracle/标签；加载器持有全时域模拟事件，不等于控制器可见 |
| 当前动作 | 已完成池、当前版本、elapsed、μ、冻结暖启动批次 | 未把在途注册的等待年龄或资源状态用于下一批次预测 |
| 未来样本 | 暖启动完成批次的群组比例、客户端和 observed_age | 不读取实际未来 payload；但未按“尚未完成”的条件残余服务分布抽样 |
| Geometry | 当前/预测 Q、年龄、共同约束 | 可求几何代理；未执行完整 RAVEN P2 |
| 计分 | 最近一次已释放 distance/age/duration，网格20.1–100 | 800时点，不把每窗当独立统计样本 |
| 审计 | 历史元数据重建与已保存轨迹 | 原审计报告通过；本轮只复算保存文件算术，不重跑其未来扰动 |

源码时间可测性的主张依赖模拟器不把隐藏事件列表传入动作接口。旧 execute 把事件处理和决策写在同一函数里，没有强类型信息隔离；新实现应拆开，不能只复制其文档表述。

## 根因事实与待验证解释

1. **确认：一步前瞻只看0.1步。** 多条到达共同补齐支持可能无法由一步边际体现；“这导致了本次失败”仍需同版本 horizon 消融。
2. **确认：预测按暖启动时钟相位抽批次，没有对在途消息条件化。** 条件残余服务、删失与漂移可能造成收益误估；需要预测校准而非把它当作已经证明的偏差。
3. **确认：规划不模拟 CLOSE后的版本增加、消费、过期和下一窗。** 实际760过期比基线568多；两者相关不证明单独的因果作用。
4. **确认：决策比较即时g，评价却是最近释放结果在共同网格上的驻留积分。** 即时排序与整个系统目标并不等价；尚无单独的损失归因实验。
5. **确认：原始Q和简化投影不是完整配置 RAVEN。** 改为校正组成是实质输入变化，但不能据此保证改善，或把旧J与新G直接排名。

这些事实支持另立明确的新规格进行审查；不足以宣布方向有效，也不足以要求尚未设计的实现先通过实验验收。
