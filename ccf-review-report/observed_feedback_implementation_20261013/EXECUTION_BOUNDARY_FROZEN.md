# 实施前冻结：信息、事务与计量边界

唯一算法为前批METHOD_SPEC_CANDIDATE.md中的OF-v1；公式、0.02/0.10/0.20、完整P2和原约束不改。四用例均为隔离确定性接口证据，SGD/GPU/q拟合/真实及随机轨迹/真实控制回放均0。45001–45003不使用。

注册时后端持有私有stage1（观测positions、权重、组mass、p、ratio）并准备合法本地工作。控制snapshot只有公开注册header、注册固定q及允许R/E状态；质量摘要在合法完成通知后才入池。注册q特征只从过去Q/V/L、当前已交付P及公开F、公开配置与学习/服务身份构造，不包含未完成私有stage1或未来表。无FrozenServiceModel构造参数，不使用假预测器。

P2NumericResult不可变，含完整实际权重、质量、数值审计及P2依赖哈希；BoundReleasePreview是另一个不可变对象，含numeric与当前snapshot指纹。缓存只复用numeric，绑定每次重新创建；旧对象/旧指纹不修改。任何提交都检查最新指纹、依赖、消息key、实际M/omega/ell与原约束。

事务选择为显式故障隔离。提交开始后若backend.apply或后续状态同步失败，runner标记fault，记录失败阶段；正常snapshot、事件推进、提交及完整检查点发布均拒绝，诊断dump允许。模型可能已改变，不能把“消息未标消费”解释为模型已回滚。只有成功完整提交才继续运行。成对文件设施不能替代这个内存一致性条件；本批不重复设施压力测试。

计量边界在首次执行前固定：一个常驻worker依次执行4用例。首次当前判断是从进程创建到空池MIN_CLIENTS返回（包括Python启动、模块导入、runner初始化、父监视与记录）；初始根成本基线0，启动器进入meter前CPU另加入首次成本。下一个代表请求是冷完整P2非强制判断，首次P2加载也计入该请求，不预热求解。随后每次当前判断包含健康检查、snapshot、必要P2或缓存、B/elapsed和返回；数据夹具构造、实际提交、真实后端加载/接线、保存/恢复分别计量并进入根总额。

根账tree+driver互斥，PID/内层Job不相加。请求前读当前根账，结束后等结束时间之后的新根账；根采样费用差加0.02 CPU秒保守量为请求上界（采样时差及计量自身包含其中，不用内部CPU替代完整费用）。首次另含launcher bootstrap。两秒门槛适用于此预先定义的完整请求上界；后续序列化与未归请求的费用在整批账中保留。局部process_time和墙钟也记录，用于解释，不能用局部值替代根结果。

输入/接线错误在同用例和预算内修复，所有失败调用保留计费；完整代表请求最终不能满足2秒、关键语义/信息/数值失格或预算耗尽则停止依赖任务并报审。不得移动边界、提高2秒或删用例。300 CPU秒含30秒阅读/编辑/交付保守费用，未逐项计量实耗未知，实测与保守费用分别报告。
