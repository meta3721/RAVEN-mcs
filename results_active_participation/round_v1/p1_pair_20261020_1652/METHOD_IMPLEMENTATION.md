# 实现

驱动是本目录的 `run_p1_pair.py`。它没有调用旧事件 runner，也没有调用模拟 U 生成器。模型类来自 `src/raven_mcs/models/common_ndmf.py`，特征公式与 `src/raven_mcs/models/features.py` 一致，但未知网格直接拒绝，不映射到下标 0。

两臂共用同一份初始参数的独立副本。初始化是 `torch.manual_seed(46001)` 后构造 118 词的 Common-NDMF。参数数为 33121。标准化使用重新计算后与冻结值一致的预热均值和总体标准差，没有优化器预热，也没有加载旧检查点。

本地损失是该客户端当日合法记录的标准化标签均方误差。手写 SGD 的学习率是 0.01，固定 2 步，每步使用全部合法记录。`delta` 是局部训练后的参数减去克隆快照。服务器更新是

`theta + 0.01 * sum_j I_j * a_j * delta_j / p_j`。

全部被选客户端都从当日更新前的同一快照训练，聚合只发生一次。

B 的组内分数是 `n_j/N_g`，C 的组内分数是 `(n_j/N_g)*h_j`。配额、capped PPS、0.2 探索和固定样本量系统抽样相同。抽样起点由种子、日期和区域的 SHA-256 决定，两臂共用。本地 dropout 的种子由主种子、日期和 client_id 决定，不含臂名。历史 EMA 系数为 0.2，第一条幅度直接初始化，7 日以后回到组先验，其余截断到先验的 [0.5, 2] 倍。历史在两臂当日都提交之后才写入。

趋势分母是截至该日结束、非 test 时间槽的个数。评价使用 2021-11-04 结束时冻结的分母 1427，初始模型和两个终点模型使用同一套评价特征。
