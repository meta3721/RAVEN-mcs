# PROOF_SKELETON — Design 删除恒等式、`ρ_r > 0` 的边界、与命题 3 的关系

```text
范围：只用当前 .tex 已写出的定义与符号。不引用本轮算出的任何数字作为证明步骤。
不出现 eq:design_switch。推不出的步骤标 GAP，不用外部论文补。
```

**符号（仅限已写出的对象）**
`D_r ∈ {on, off}`：Design 因子（`eq:design_factor`，配置）；`π^tar_{k,s}`：公共目标质量；
`π̂^opp`：滞后的机会估计；`π_min > 0`：A6a 的下限；`E_r`：窗口 `r` 的已送达单元集合；
`A_r ⊆ U_r`：正质量 client 集合；`ρ_r = n^zero_r / n_r`：`eq:design_gate` 在已送达单元上的比例；
`ζ^o_{k,r,i}`：Design-on 权重（`eq:design_ratio_simple`）；`π_min` 与 `max{·, π_min}` 使分母严格为正。

---

## 1. 删除恒等式

**命题（恒等式）。** 在 `eq:design_ratio_simple` 下，对任一已送达单元 `(k,i) ∈ E_r`：

```text
D_r = on :  ζ^o_{k,r,i} = 0   ⟺   π^tar_{k,s(i)} = 0
D_r = off:  ζ^o_{k,r,i} = 1   （恒正）
```

**推导。** `D_r = on` 时 `ζ^o = π^tar / max{π̂^opp, π_min}`，分母由 A6a（`π̂^opp ≥ π_min`）与 `π_min > 0` 保证严格为正，故该权重为零当且仅当分子 `π^tar = 0`。`D_r = off` 时权重恒为 1。

**推论（门与删除等价）。** `D_r = on` 不删除任何已送达单元，当且仅当 `ρ_r = 0`。
（`ρ_r = 0` ⟺ `E_r` 中不存在键为零的单元 ⟺ 每个已送达单元权重为正。）

**边界（已写出的限制）。** 该恒等式只刻画 **Design 因子**这一条零权重通道。已送达单元仍可能在
正权重/P2 支撑层被排除（§VII-E 的 774 窗口核对即针对该层），本恒等式对该层不作任何断言。
**该恒等式对任何公共目标图都成立**（M1、M2、评估派生图皆然），且**不涉及 `ε_π`**。

---

## 2. `ρ_r > 0` 的下界

**可得的部分（等式，不是下界）。** 单元计数份额恰为 `ρ_r = n^zero_r / n_r`，按定义即得，无需额外假设。
若把 `ρ_r` 乘以 Design-on 下的平均权重，得到的仍不是下界，而是"被删质量占比"的另一种写法。

**GAP。** 要给出**被删质量占比**的一个数据无关正下界，需要每个被删单元在 Design-on 权重下的
**正权重下界**。由 `eq:design_ratio_simple` 与 `eq:design_gate` 的现有定义无法得到这样的下界：
`π^tar > 0` 可以任意小，而 `π̂^opp` 只被 A6a 从下方约束，故 `ζ^o = π^tar / max{π̂^opp, π_min}`
在 `π^tar > 0` 时仍可任意接近 0，不存在与数据无关的 `ζ^o ≥ ζ_floor > 0`。
→ 因此"被移除质量占比 × 常数"这种写法**不能**从现有定义推出；本轮按协议标 `GAP`，不以外部结果补。
（闭合该 GAP 需要一条新增的权重要求，例如对 `π^tar ≥ π^tar_min > 0` 的显式下界假设；本轮不引入。）

---

## 3. 与命题 3 的边界

命题 3 的前提包含：理想参考与实现参考**共享同一 `A_r`**，并在此前提下给出
`‖β̂_r − β_r^⋆‖₁ ≤ C₁(ε_π + ε_p + ε_q) + ε_stab,r`。

- `ρ_r > 0` 时，Design 删除的单元使**实现**的 `A_r` 与理想的 `A_r` 不同 → 命题 3 的共享前提不成立，
  **命题 3 不被适用**，其界不能被引用来评价该情形。
- `ρ_r = 0` 时，第 1 节的推论说明 Design 因子不再删除已送达单元，这**只去掉这一条障碍**；
  它**不推出** `ε_π = 0`（`ε_π` 是机会估计误差，与 `π^tar` 是否为零无关），也不推出
  `ε_p = ε_q = ε_stab = 0`。命题 3 的界在该情形下仍然只是一个上界，其三项误差各自照旧。
- 因此本骨架**不断言** `ρ_r = 0 ⇒ ε_π = 0`，也**不把** `eq:design_switch` 写成任何推论。

---

## 结论（可直接引用的三句）

1. 已送达单元的 Design 权重为零，当且仅当它所在键的公共目标质量为 0；故门 `ρ_r = 0` 与
   "Design 不删除已送达单元"等价。这是恒等式，对任何公共图成立，且与 `ε_π` 无关。
2. `ρ_r > 0` 时，计数份额就是 `ρ_r`；质量份额的数据无关正下界**推不出**（`GAP`）。
3. `ρ_r > 0` 使命题 3 的共享 `A_r` 前提失效，故命题 3 在该情形不被适用；`ρ_r = 0` 只移除这一障碍，
   不推出任何插值误差为零。
