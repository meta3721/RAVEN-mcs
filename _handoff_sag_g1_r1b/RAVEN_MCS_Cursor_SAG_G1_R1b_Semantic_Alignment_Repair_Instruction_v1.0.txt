六、R1b-B：Opportunity-event mass repair
============================================================

当前重点是：
  不允许把“是否出现过某 pair”当成 opportunity mass。

------------------------------------------------------------
R1b-B.1 定义真实 completed-window event counts
------------------------------------------------------------

对 completed window t：

  N^{opp}_{k,s,t}
  =
  sum over opportunity events e in E_t^{opp}
  1{ k_e=k, s(i_e)=s }

如果 EventTrace 有 event weight：
  使用真实 event mass；
否则：
  每个 opportunity event 计数 1。

总质量：

  N_t^{opp}
  =
  sum_{k,s}
  N^{opp}_{k,s,t}

若 N_t^{opp}>0：

  pi^{opp}_{k,s,t}
  =
  N^{opp}_{k,s,t}/N_t^{opp}

若没有 opportunity event：
  按既有 cold-start/missing-window 规则处理，
  不得伪造均匀分布。

------------------------------------------------------------
R1b-B.2 禁止 unique-pair uniformization
------------------------------------------------------------

搜索并移除/隔离类似逻辑：

  unique_pairs = set(...)
  mass = 1.0 / len(unique_pairs)

若该逻辑还用于其他 diagnostic：
  可以保留，但重命名为：
    pair_presence_distribution
  并明确不得进入 SAG C_cov。

------------------------------------------------------------
R1b-B.3 lagged opportunity mass
------------------------------------------------------------

在线 window r 的 Gate 只能使用 completed windows < r。

构造：

  pi_hat^{opp}_{k,s,r}

使用：
  completed event counts / lagged state。

允许使用现有 EMA：
  C^{opp}_{k,s,r}
  =
  rho C^{opp}_{k,s,r-1}
  +
  N^{opp}_{k,s,r-1}

然后：

  pi_hat^{opp}_{k,s,r}
  =
  normalized C^{opp}_{k,s,r}

但必须：
  current r 的 N^{opp} 不进入 current Gate。

------------------------------------------------------------
R1b-B.4 lower bound
------------------------------------------------------------

对每个 target-positive (k,s)：
  计算 pre-window one-sided lower bound：

  lower_pi^{opp}_{k,s,r}

本轮不重新发明复杂模型。
优先：
  用 R1 中已实现的 LCB 框架，
  但输入必须从 event mass 改为正确的 pi_hat^{opp} history。

------------------------------------------------------------
R1b-B.5 C_cov
------------------------------------------------------------

严格计算：

  C_cov_LCB(r)
  =
  sum_{k,s}
    pi_tar(k,s)
    1{
      lower_pi_opp(k,s,r) >= pi_safe
    }

要求：
  target-mass weighted；
  不是 pair-count fraction；
  不是 current R coverage；
  不是 realized support overlap。
